# 📊 23_能源转换工具多Agent评估与全维重构方案

## 1. 业务背景与重构定位

特变电工（电装集团）下辖 15 大现代化工业园区与 21 家重型制造基地。在“零碳园区集控中心”与“产品碳足迹集采中心”建设中，**能源转换与折标核算**是贯穿底层 SCADA 数据采集、车间月度报表填报、工序单耗考核、产品 LCA 碳足迹模型以及欧盟 CBAM 碳关税申报的**基石级计算引擎**。

---

## 2. 核心功能架构

```mermaid
graph TD
    User([用户/能管员/工艺工程师]) --> ModeSelect{模式选择}
    ModeSelect -->|模式 A| Single[⚡ 单介质快速换算器]
    ModeSelect -->|模式 B| Batch[📊 多介质综合折标批量核算]
    ModeSelect -->|模式 C| Dict[📖 国标折标字典速查]

    Single --> S1[12+工业介质选择 + 当量/等价折标口径]
    S1 --> S2[标煤tce / 热值MJ / 碳排tCO2 / 成本RMB 4大HUD]
    S2 --> S3[动态数学公式推导过程展示 + 一键复制]

    Batch --> B1[典型工厂车间模板装载: 沈变干燥/衡变特高压/鲁缆交联]
    B1 --> B2[一键汇算总标煤 tce + 总碳排 tCO2 + 综合费用]
    B2 --> B3[能耗结构占比横向分布条 + 账单明细表]

    Dict --> D1[GB/T 2589-2020 官方折标系数与碳排因子]
    D1 --> D2[分类标签筛选 + 模糊搜索]
```
