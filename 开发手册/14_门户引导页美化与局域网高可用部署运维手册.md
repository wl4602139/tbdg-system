## 🎨 一、门户引导页（Portal View）设计与交互规范

### 1.1 视觉调性与动态背景体系
* **主色调与色彩哲学**：
  * **零碳园区集控中心**：采用 TBEA 标志性**皇家科技蓝**（`#1677ff` / `#003eb3`），象征能源管控的稳健与工业算力；
  * **产品碳足迹集采中心**：采用**低碳翡翠绿**（`#10b981` / `#059669`），象征生态低碳、绿色供应链与出海合规；
* **动态通透弥散光晕背景**：
  * 彻底移除点阵/颗粒背景，采用自然清爽的三阶渐变：`bg-gradient-to-b from-[#f8fafc] via-[#edf3fa] to-[#e6eff9]`；
  * 左右双角部署超大半径（`blur-3xl`）的蓝绿环境光晕球，中间辅以微细半透明流光线条，提供深邃通透的工业物联网质感。

### 1.2 双中心 3D 玻璃拟态卡片交互
* **微动效与浮动层级**：
  * 鼠标悬停（Hover）触发 `-translate-y-1.5` 轻量 3D 悬浮与 `shadow-xl` 景深阴影扩展；
  * 右上角能量光环扩散动画，卡片内行动点按钮（CTA）带渐变底色与右箭头平移（`translate-x-1`）；
* **实时工况动态提示条**：

## 🚀 三、局域网多端访问与生产部署避坑指南

### 3.1 局域网访问无响应深度排查（Root Cause Analysis）
* **现象描述**：同局域网内其他设备访问开发服务时，页面虽能渲染，但按钮点击与抽屉弹窗完全无响应；
* **根本原因**：
  * Next.js 16+ 在开发模式（`next dev`）下默认启用了严格的安全策略，会拦截跨域来源（非 localhost 的局域网 IP 如 `10.131.43.10`）的 `/_next/hmr` 与热重载脚本注入，导致**客户端 JavaScript 代码未能成功 Hydrate，React 事件委托失效**。

### 3.2 生产级运维解决方案
生产环境运行（Production Mode）彻底移除了 HMR 跨域拦截机制，性能提升 5 倍以上：
1. **生产打包编译**：
   ```bash
   pnpm build
   ```
2. **全网卡绑定生产启动**：
   ```bash
   pnpm start
   # 对应底层执行：next start -H 0.0.0.0
   ```
3. **局域网多端访问端口**：
   * 本机访问：`http://localhost:3000`
   * 局域网平板/手机/办公电脑：`http://10.131.43.10:3000`
