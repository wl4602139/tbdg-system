# 🏭 特变电工能碳管控平台 · 指标管控 (4 维硬核 PK) 多 Agent 综合评估与优化方案

> **评估对象**：`/zero-carbon/monitor/indicator`（指标管控 · 4 维横向硬核 PK 看板）  
> **评估团队**：Antigravity Multi-Agent 专家组 (PM, UI/UX, Architect, Frontend, QA, Security)  
> **核心宗旨**：“用数据抓管理，用对比分优劣；架构树状穿透，视觉粗暴醒目，边界只展不核”

---

## 1. 👨‍💼 产品经理视角 (PM) 评估与建议

### 🔍 现状诊断
1. **已达成**：落实了“树状穿透”与 4 大硬核 PK 维度（工厂间、同产品跨厂、同厂产线、批次波动），优劣高反差红绿标记已就绪；
2. **待补强痛点**：
   * **管理缺乏闭环动作**：领导看到“新变超高压严重超标 +48.3%”后，缺少一步到位的闭环动作（如【发起工单/节能督办单】或【一键生成异动诊断简报】）；
   * **对比缺乏直观视觉差**：纯数字对比容易产生审美疲劳，缺乏**横向对比柱状差值条 (Bar Diff)**，无法一眼看出第 1 名比第 2 名多耗能多少倍；
   * **缺少基准线硬指标对齐**：同产品跨厂 PK 应常驻“国家/行业标杆线 (Benchmark)”与“集团平均线”。

### 💡 优化方案
* **增加横向可视化差值能量条**：在每个列表项中间增加彩色比例条（超标为刺眼红渐变，达标为翠绿渐变）；
* **管理闭环联动按钮**：在红色重点监管工厂/产线右侧提供 **【督办整改】** 与 **【查看工序能流】** 快捷穿透；
* **一键导出对标报告**：右上角增加 **【导出本月 PK 对标红黑榜 PDF/Excel】**。

---

## 2. 🎨 UI/UX 设计师视角评估与建议

### 🔍 现状诊断
1. **版面留白与高度平衡**：右侧列表卡片排布较为扁平，垂直方向下半区留白较多，左侧架构树与右侧视口高度未完全拉齐；
2. **信息层级对比度**：
   * 排名序号徽标（1、2、3）视觉张力需进一步强化；
   * 核心数值（如 `1520 tce`、`4150.2 tCO2`）字号需加大并突出单位，与原因说明形成清晰的主次视觉层级；
3. **架构树精细度**：左侧树状分支虚线较浅，增加微搜索框与展开/折叠全部按钮。

### 💡 优化方案
* **Bento Grid + 排名红黑榜视觉强化**：
  * 第 1 名最耗能（红榜警戒）：大红微发光边框 + 醒目红色数字 + 呼吸感预警标；
  * 能效标杆（绿榜标杆）：翠绿高光边框 + 标杆奖杯金绿徽章；
* **树组件增加动态检索**：顶部增加 `搜索工厂/车间/产品...` 快速过滤输入框；
* **高度自适应填充**：左右两栏拉齐视口高度，卡片内信息密度适中、主次分明。

## 3. 🛠️ 架构师视角 (Architect) 评估与建议

### 🔍 现状诊断
* **严格遵守“只管展示不管核算”的系统边界**：
  * 指标管控模块只负责接收外部核算引擎传入的标准化指标 JSON，不介入底层复杂的碳足迹生命周期建模与能耗换算；
* **数据结构建议统一为标准 PK 契约模型**：
  ```typescript
  interface PkMetricItem {
    id: string
    rank: number
    entityName: string          // 工厂/产线/批次名称
    entityCode: string
    actualEnergy: number        // 实际综合能耗 (tce)
    actualCarbon: number        // 实际碳排放 (tCO2)
    greenRatio: number          // 绿电占比 (%)
    benchmarkEnergy?: number    // 行业/集团标杆值
    deltaRatio: number          // 超标/节能量百分比 (+18.4% / -8.6%)
    status: 'worst' | 'best' | 'normal' | 'warning'
    diagnosis: string           // 工艺异动归因排查结论
    lossCost?: string           // 超标额外成本 (万元)
  }
  ```

## 4. 💻 前端工程师视角 (Frontend) 评估与建议

### 🔍 现状诊断与实现建议
1. **抽屉式详情穿透 (Detail Drawer)**：
   * 点击任意一家工厂或产线，右侧平滑滑出抽屉，展示：
     * 近 6 个月历史单耗趋势曲线；
     * 关键工序能耗构成（干燥、试验、叠装、空压）；
     * 实时遥测负荷与异常报警记录；
2. **多模式视图切换**：
   * 提供 **【列表 PK 视图】** ↔ **【柱状排行图表视图 (Bar Chart)】** 一键切换；
3. **响应式与等宽字体**：
   * 所有核心数值强制使用 `font-mono font-extrabold`，确保大屏与桌面端数字对齐整齐。
