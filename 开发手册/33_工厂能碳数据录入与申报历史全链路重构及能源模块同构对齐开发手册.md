## 📌 一、 业务背景与架构定位

特变电工“零碳园区集控中心 + 产品碳足迹集采中心”数字化平台中，工厂能碳数据填报（`entry`）承担着基层制造分厂（沈变、衡变、新变、鲁缆等）每月核心工业生产产品（变压器、电抗器、硅钢铁心等）完工产量、7 大物理能源介质（电、水、气、汽、柴油等）以及财务发票支出的数据归集工作。

本手册针对系统从早期“松散表单模式”向“**高密度列表化、4级工业级联选配、按自然月归档管理、全量申报档案在线闭环**”的架构演进进行完整技术沉淀。

## 🏛️ 二、 核心数据模型与契约结构

### 1. 月度申报批次档案模型 (`MonthDeclarationBatch`)
```typescript
export interface MonthBatchProductItem {
```

### 2. 状态字典与时序切换机制
为了支撑多月份申报数据的快速无缝切换，工程采用双时序映射字典：
```typescript
// 月度产品台账字典: '2026-08' -> ProductItem[]
const [monthlyProductsMap, setMonthlyProductsMap] = useState<Record<string, ProductItem[]>>({...})

// 月度能源指标字典: '2026-08' -> MetricItem[]
const [monthlyEnergyMap, setMonthlyEnergyMap] = useState<Record<string, MetricItem[]>>({})
```
在切换申报月份函数 `handleSwitchReportingMonth(newYear, newMonth)` 中：
1. 自动快照保存当前 `selectedYear-selectedMonth` 下的 `activeProducts` 和 `metrics`；
2. 加载目标月份已有数据或基于预置历史批次进行精准还原；
3. 杜绝因月份切换导致的数据丢失或错乱。

## 🎨 三、 工业人机交互与反过度设计准则

### 1. 三位一体工具栏规范（双模块 100% 对齐）
无论是【产品产量】还是【能源消耗】模块，标题卡片右侧均统一采用三位一体工具栏：
- **位置 1 · 申报月份选择器**：`[ 📅 申报月份: 2026年08月 ▾ ]`
- **位置 2 · 主添加按钮**：
  - 产品产量：`[ + 添加产品 ]`
  - 能源消耗：`[ + 添加类型 ]`
- **位置 3 · 历史台账入口**：`[ ⏱ 历史台账 ({monthBatches.length}期) ]`

### 2. 月份选择器防误触状态机
- 下拉 4x3 月份矩阵弹窗；
- **已申报归档月份**（2026-01 至 2026-07）：样式呈现为中划线、文字透明度 35%、带 `cursor-not-allowed select-none`，彻底禁止点击选择，保证历史审计归档的严肃性；
- **当前填报月份**（2026-08）：高亮主色背景、加粗 Mono 字体、带「填报中」状态；
- **未申报月份**：呈现「待申报」状态并支持点击直接切换。

### 3. 表格 44px 强制行高与数据对齐
- 全站数据表格严格遵循 `h-[44px]`，垂直居中对齐；
- 具备 RowSpan 连续同类别单元格纵向合并能力（如变压器下多规格、实物消耗量下多介质），居中展示分类名称与项数，大幅降低信息重复噪点；
- 行内直接配备计划产量与完工数量输入框，失焦与回车实时重算品类总产量与财务支出；
- 操作列提供 `<Edit3>` 编辑与 `<Trash2>` 删除按钮，点击编辑唤起标准化参数修改弹窗。

### 4. 彻底剥离多余说明与衍生卡片（极简工业形态）
- **工作台**：全面移除原产品产量与能源消耗表格上方的 8 张汇总 KPI 卡片行，首屏直达高密表格；
- **历史台账**：
  - 彻底移除表格中的【申报批次号】列（DR-xxxxxx-xx 等内部技术码）；
  - 彻底剔除历史台账中部的 4 张微统计卡片行（批次统计、覆盖品类、最高支出、最新申报），消除二阶冗余；
  - 表格精炼为 9 大主干列。

## 📂 四、 申报全量档案详情弹窗 (`MonthDeclarationDetailModal`)

### 1. 结构与功能设计
- **双核心业务 Tab 架构**：
  1. **产品产量清单**：当月各细分型号计划产量、实际完工产量、计量单位直接表格展示与行内编辑；
  2. **能源消耗与支出费用**：7 大物理实物介质与 5 大发票支出费用参数展示与行内编辑；
- **双向流转闭环**：
  - 弹窗底部提供 `[退回到填报工作台]` 快捷入口；
  - 智能感知当前处于的产品或能源 Tab，退回时无缝定位到对应的填报视图；
  - 点击 `[保存全部修改并入库]` 自动更新历史批次数据源，重算摘要并触发全局 Toast。
