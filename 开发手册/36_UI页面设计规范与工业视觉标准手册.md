## 一、 编制背景与核心设计哲学 (Design Philosophy)

### 1.1 建设背景
特变电工能碳数字化双中心（零碳园区集控中心 + 产品碳足迹集采中心）服务于集团决策层、园区集控中心调度员与生产工厂车间管理人员。为了彻底解决前期原型中存在的色彩混杂、面板层级不一、控件尺寸跳跃、导航密度偏低以及自述式描述等工业噪音问题，特变电工官方正式下发《UI页面修改 (2).pdf》，对全系统的全局色彩体系、面板容器、卡片信息层级、侧边导航与组织架构树人机工程、以及核心控制控件（TAB/导出按钮/输入与下拉框）进行了全方位的标准化统一。

### 1.2 核心设计准则：工业实用主义与极致克制
1. **统一 Design Tokens**：所有色彩、边框、圆角、行高与间距严格遵循 Design Tokens 体系，杜绝私自硬编码临时样式；
2. **状态自解释，反过度设计**：严禁添加“图表联动中”、“已选中”等描述性标签，激活态统一通过实心背景或边框光晕自解释表达；
3. **数字即结论，去噪提效**：卡片与图表直接呈现核心数值与物理量，杜绝自说自话的操作提示与说教性评价文案；
4. **双端 100% 同构一致性**：暗黑科技蓝端（3000端口）与浅色商务办公端（3001端口）在组件尺寸、数据流与业务口径上保持绝对镜像一致。

## 二、 全局基础视觉规范 (Global Design Tokens)

### 2.1 页面背景与面板容器

| 视觉要素 | 规范参数值 | Tailwind CSS 类名 / 变量 | 设计人机工程说明 |
| :--- | :---: | :--- | :--- |
| **页面主背景色** | `#F3F7FB` | `bg-[#F3F7FB]` / `bg-background` | 统一全站浅色办公端主底色，柔和微透浅灰蓝，消除纯白眩光疲劳 |
| **面板/卡片填充** | `#FFFFFF` | `bg-[#FFFFFF]` / `bg-panel` / `bg-card` | 纯白卡片背板，高对比承载图表与数据指标 |
| **面板描边边框** | `#DBE6EE` | `border-[#DBE6EE]` / `border-border` | 精细浅蓝灰工业描边，区分面板板块边界 |
| **面板/卡片圆角** | `8px` | `rounded-lg` (`rounded-[8px]`) | 工业适中倒角，沉稳硬朗且兼顾现代感 |
| **面板统一外间距** | **`24px`** | `gap-6` / `space-y-6` (`gap-[24px]`) | 页面级各大业务板块之间的标准外边距与网格槽宽 |

### 2.2 字体排版与阶梯层级 (Typography Hierarchy)

全系统严格遵循四级字体层级体系，杜绝字号繁杂失控：

| 层级对象 | 规范字号 | 字重要求 | 字体族规范 | 适用场景说明 |
| :--- | :---: | :---: | :--- | :--- |
| **正文内容** | **`14px`** | 常规 (`font-normal`) | 系统默认 Sans (`Inter`, `PingFang SC`) | 表格单元格文本、表单标签、普通辅助描述、图表轴刻度 |
| **面板主标题** | **`16px`** | 加粗 (`font-semibold` / `font-bold`) | 系统默认 Sans | 面板头部标题（如“各经营单位产品碳足迹排序”）、弹窗标题 |
| **卡片标题** | **`14px`** | 常规/微粗 (`font-medium`) | 系统默认 Sans | 顶部指标卡片、KPI 概览卡片标题（如“综合能源消费量”） |
| **卡片核心主数值** | **`24px`** | 加粗 (`font-bold` / `font-extrabold`) | 等宽字体 Mono (`JetBrains Mono`, `Roboto Mono`) | KPI 核心数值（如 `12845`、`0.313`），保障数字对齐与冲击力 |
| **其他辅助字号** | **`14px`** | 常规 (`font-normal`) | Sans / Mono | 物理计量单位（如 `tce`、`万kVA`）、时序对比文本（“同比”） |

## 四、 侧边导航与组织架构树规范 (Sidebar & Topology Tree)

### 4.1 侧边导航栏样式 (Sidebar Navigation)
1. **导航栏宽度**：统一固定为 **`260px`**（`w-[260px]`），保障中文菜单不折行、菜单徽章展示从容；
2. **Logo 规范**：原文本 Logo 全面替换为特变电工官方高清矢量 Logo 图片；
3. **Logo 下方主标题与英文描述**：
   - 中文大标题：“**零碳园区集控中心**”（大号白字加粗，`text-lg font-bold text-white`）；
   - 英文副标题：“**PARK CENTRALIZED CONTROL CENTER**”（全大写浅蓝细体，`text-[10px] text-white/70 tracking-wider`）；
4. **业务中心选择器迁移**：
   - 原位于顶栏的“选择切换业务中心”功能**彻底迁移至左侧导航栏**，位于 Logo 与系统大标题正下方；
   - 采用半透明胶囊下拉控件（`[图标] 零碳园区集控中心 [ChevronDown]`），支持一键无缝切换【零碳园区集控中心】与【产品碳足迹集采中心】；
5. **导航菜单间距**：导航项垂直文字间距增大到 **`30px`**（行距/内边距舒适通透）。

---

### 4.2 企业组织拓扑树样式 (Organization Topology Tree)
依据《UI页面修改 (2).pdf》第 3、4 页参考设计：
1. **容器底色与边框**：纯白底色 `#FFFFFF`，描边边框 `#DBE6EE`，圆角 `8px`；
2. **头部标题栏**：左侧蓝色建筑图标 `Building2` + 14px 标题“企业组织拓扑”；
3. **搜索框规范**：
   - 带放大镜图标 `Search`；
   - 占位符提示“请输入搜索关键词”；
   - 描边 `#DBE6EE`，圆角 8px，白底；
4. **树节点行距与文字间距**：垂直间距统一调整为 **`30px`**（`h-[30px]` / 行高 30px）；
5. **层级语义图标**：
   - 集团 / 二级单位：采用建筑图标 `Building2`；
   - 单体工厂 / 实体车间：采用架构方块图标 `Network`；
6. **选中激活态 (Active State)**：
   - 激活节点呈现浅蓝圆角底色 **`#EBF3FF`**；
   - 节点文字加粗深蓝高亮，完全自解释，不增设任何说明标签。

## 五、 卡片与控制组件标准规格 (Cards & Controls)

### 5.1 标准指标卡片样式 (KPI Metric Card)
依据《UI页面修改 (2).pdf》第 5 页图示标准：
- **卡片容器**：白底 `#FFFFFF`，描边 `#DBE6EE`，圆角 `8px`，内边距 `p-4`；
- **顶部行**：
  - 左侧：卡片标题（14px，常规色，如“综合能源消费量”）；
  - 右侧：柔和绿色胶囊状态标签（如“国家级零碳工厂”，浅绿背景带边框）；
- **中部行**：
  - 左侧：大号加粗主数值（**`24px`**，Mono 等宽，如 `12845`） + 物理计量单位（**`14px`**，浅灰，如 `tce`）；
  - 右侧：浅蓝背景微型圆角操作按钮“详情”；
- **底部行**：
  - 左侧：时序对比标签（**`14px`**，浅灰，如“同比”）；
  - 右侧：变动率与趋势方向（**`14px`**，浅蓝或红绿语义色，如 `-4.8% ↗`）。

---

### 5.2 TAB 切换组件规范 (Segmented Tabs)
- **容器与排版**：水平排列，无多余外框；
- **未选中态**：字体 14px，浅灰或深灰文本，无背景色，悬停轻微提亮；
- **选中激活态**：
  - 背景填充：实心主题科技蓝 **`#2C7CFF`**；
  - 文字颜色：纯白 **`#FFFFFF`**，字体加粗；
  - 圆角规格：**`8px`**；
  - 示例：`[ 月度 ]   季度    年度`。

---

### 5.3 导出按钮规范 (Export Button)
系统内所有数据导出、报表下载按钮必须全面遵循统一标准：
- **宽度**：固定为 **`80px`**；
- **高度**：固定为 **`36px`**（`h-9`）；
- **填充颜色**：主题科技蓝 **`#2C7CFF`**；
- **圆角规格**：**`8px`**；
- **内部元素**：白色托盘导出图标（`Download` / `Upload`） + 白色文字“**导出**”；
- **范围约束**：全系统所有模块导出按钮 100% 同步执行。

---

### 5.4 输入框与下拉选择框规范 (Input & Select)
- **推荐宽度**：统一为 **`200px`**（`w-[200px]`，可根据具体长文本自适应弹性扩展）；
- **固定高度**：统一为 **`36px`**（`h-9`）；
- **填充背景色**：纯白 **`#FFFFFF`**；
- **描边边框**：浅蓝灰 **`#E2E8F0`**（或 `#DBE6EE`）；
- **圆角规格**：**`8px`**；
- **前置标签排版**：左侧前置中性灰色标签（如“搜索”、“选择部门”），右侧承接 200px × 36px 规范选择框，右侧内置极简 `ChevronDown` 下拉箭头。

## 六、 开发者自查与 QA 验收清单 (Checklist)

| 检查大类 | 关键指标 / 验收点 | 合规标准 | 违规反模式 (严禁) |
| :--- | :--- | :--- | :--- |
| **色彩合规** | 8 大能源介质色 | 电`2C7CFF`、市电`41C0FF`、绿电`00D492`、水`10C4CE`、气`FF6536`、汽`FFBA00`、油`8E73ED`、氮`4F39F6` | 出现暗黄、偏绿或临时 Tailwind 颜色 |
| **色彩合规** | 4 段峰平谷分时色 | 尖`FF6536`、峰`FFBA00`、平`2C7CFF`、谷`10C4CE` | 尖峰使用普通黄色或低谷使用纯灰色 |
| **容器尺寸** | 面板间距与圆角 | 间距固定 **`24px`**，圆角固定 **`8px`**，描边 **`#DBE6EE`** | 间距过窄（如 8px/12px）或圆角过大（如 16px/24px） |
| **字号阶梯** | 标题与数值字号 | 面板标题 **`16px加粗`**，卡片标题 **`14px`**，核心数值 **`24px加粗`** | 卡片标题使用 12px 或数值过小 |
| **侧边导航** | 宽度与间距 | 宽度 **`260px`**，Logo 下方带中英文标题，切换业务中心在左侧，文字间距 **`30px`** | 宽度依然为 240px，切换业务中心遗留在顶栏 |
| **组织树** | 间距与选中态 | 节点行距 **`30px`**，激活选中态底色为浅蓝 **`#EBF3FF`** | 间距拥挤密集，选中态为刺眼深蓝或无背景 |
| **控制组件** | TAB、导出与输入框 | 激活Tab`#2C7CFF`圆角8px；导出按钮`80×36px`；输入/下拉框`200×36px`纯白底色 | 导出按钮忽大忽小、输入框高度非 36px |
| **表格规范** | 表格行高 | 强制固定为 **`44px`**，垂直居中 | 行高自适应或过高过低 |
| **客观中立** | 去除主观定性评价 | 纯客观时序（环比/同比/基准偏差量），无主观定性褒贬文字 | 出现“优良”、“合格奖励”、“落后单位”等主观文字 |
