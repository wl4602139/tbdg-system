## 一、 编制背景与设计哲学 (Background & Philosophy)

### 1.1 需求背景与痛点回顾
在特变电工“双中心”（零碳园区集控中心 + 产品碳足迹集采中心）平台演进过程中，左侧导航栏的头部区域此前存在若干视觉与交互偏差：
1. **Logo 衬底冗余卡片**：此前将 Logo 放入一个白色圆角实体卡片（`bg-white rounded px-1.5 py-0.5`）中缩放呈现，与深蓝背景产生生硬的视觉割裂；
2. **非对称偏左排版**：Logo、中文大标题与英文副标题均为左对齐，且右侧挤占了折叠按钮，破坏了工业监控系统的中轴对称美感；
3. **英文副标题意外折行**：由于字号设置偏大（`9.5px`）、间距过宽且缺少不可折行约束，在标准 260px 宽度侧边栏下，`PARK CENTRALIZED CONTROL CENTER` 中的“CENTER”在部分视口下掉落至第二行；
4. **子菜单垂直居中缺失**：子菜单因 `block h-[30px] leading-[30px]` 属性导致文字靠近顶部、底部空出大面积留白，缺乏垂直居中的工业精致度。

根据官方最新下发的《UI页面修改 (2).pdf》权威设计规范及用户最新核验截图，本手册正式固化左上角品牌区域与双中心导航交互的工程实现标准。

## 二、 核心规范与 Design Tokens (Design Standards)

### 2.1 整体空间与布局网格
- **侧边导航栏总宽度**：固定为 **`260px`** (`w-[260px]`)；
- **品牌头部容器**：
  - 布局模式：严格采用 **垂直堆叠、绝对水平居中**（`flex flex-col items-center text-center`）；
  - 容器内边距：`px-4 pt-6 pb-5`（横向留白 16px，内容有效宽度 228px；纵向舒展，黄金比例呼吸感）；
  - 底部分割线：微透白线 `border-b border-white/15`（暗黑端为 `border-b border-sidebar-border`）。

### 2.2 视觉元素四级阶梯规范

```
┌───────────────────────────────────────────┐  <- 260px 侧边栏
│                 pt-6                      │
│            [TBEA 特变电工]                │  <- 1. 官方纯白矢量 LOGO (h: 22px, 居中)
│                 mt-4                      │
│            零碳园区集控中心                │  <- 2. 中文大标题 (18px 加粗, 居中)
│                mt-1.5                     │
│    PARK CENTRALIZED CONTROL CENTER        │  <- 3. 英文副标题 (8px, 强制单行, 居中)
│                 mt-5                      │
│   ┌───────────────────────────────────┐   │
│   │ (🌐) 零碳园区集控中心           ∨ │   │  <- 4. 业务中心切换圆角胶囊 (h: 42px)
│   └───────────────────────────────────┘   │
│                 pb-5                      │
├───────────────────────────────────────────┤  <- border-b border-white/15
│ 导航菜单项 (h-36px, 垂直居中)              │
```

#### 1. 官方纯白矢量 LOGO (`/logo-white.png`)
- **资产来源**：从官方《UI页面修改 (2).pdf》提取的高保真纯白矢量 PNG（分辨率 440×38，RGBA 透明通道）；
- **尺寸规则**：高度固定为 **`22px`**（`h-[22px] w-auto object-contain mx-auto`），按 11.58 宽高比自动适配宽度为约 208px，在 228px 内容区内居中呈现；
- **反冗余约束**：严禁在 Logo 外层包裹任何实体白底卡片或色块，纯白 Logo 必须直接浮现于深蓝/暗黑背景之上。

#### 2. 系统中文大标题
- **字号与字重**：**`18px`** (`text-[18px]`)，粗体 (`font-bold`)；
- **字体色彩**：纯白 (`text-white`)；
- **字间距与行高**：微松弛字距 `tracking-[0.06em]`，行高 `leading-tight`；
- **文字自适应**：
  - 零碳园区集控中心模式：显示为 **“零碳园区集控中心”**；
  - 产品碳足迹集采中心模式：显示为 **“产品碳足迹集采中心”**。

#### 3. 系统英文小字（单行强制约束）
- **字号与字重**：**`8px`** (`text-[8px]`)，中等字重 (`font-medium`)；
- **字体色彩**：微透高对比白 (`text-white/75`)；
- **字间距与排版**：大写字母间距 `tracking-[0.1em]`，大写转换 `uppercase`；
- **单行硬性防御**：显式注入 **`whitespace-nowrap`** 与 `leading-none`，彻底阻断任何跨端分辨率下的折行风险；
- **英文对照**：
  - 零碳园区集控中心：`PARK CENTRALIZED CONTROL CENTER`；
  - 产品碳足迹集采中心：`PRODUCT CARBON FOOTPRINT CENTER`。

#### 4. 业务中心选择器圆角胶囊 (`DualCenterCapsule`)
- **外观形态**：`rounded-xl border border-white/40 bg-white/10 hover:bg-white/15 active:bg-white/20 px-3.5 py-2.5 shadow-xs backdrop-blur-xs`；
- **内部左侧**：纯白 `Globe` 地球线条图标（size-5，不含背景方块），搭配 14px 中等粗细标题文字（`text-[14px] font-medium text-white`）；
- **内部右侧**：纯白 `ChevronDown` 箭头（size-4，展开时顺畅旋转 180 度）；
- **弹窗交互**：点击平滑展开浮层（浅色端纯白实底卡片带阴影，暗黑端科技蓝毛玻璃背板），支持零碳园区集控中心与产品碳足迹集采中心一键切换。

## 三、 导航栏垂直居中与人机工程标准 (Navigation Ergonomics)

针对侧边导航栏及下属组织架构树，全面统一垂直居中机制：

| 组件节点 | 规范高度 | 对齐实现机制 | 状态样式标准 |
| :--- | :---: | :--- | :--- |
| **一级主导航项** | **`36px`** | `flex items-center px-3 h-[36px]` | 激活态实心蓝胶囊 / 悬停柔光 |
| **二级子导航项** | **`32px`** | `flex items-center px-2.5 h-[32px]` | 激活态科技蓝底白字 / 彻底消除文字顶偏 |
| **组织拓扑树节点** | **`30px`** | `flex items-center px-2 h-[30px]` | 激活态圆角浅蓝 `#EBF3FF` + 蓝字 `#2C7CFF` |
| **折叠切换按钮** | **`32px`** | 统一定位于主工作区顶栏面包屑左侧 | 消除对侧边栏品牌区域水平对称性的破坏 |

## 四、 代码实现与架构指引 (Implementation Architecture)

### 4.1 核心组件实现片段 (`components/shared/platform-shell.tsx`)

```tsx
{/* 顶部特变电工官方 LOGO 品牌栏 + 业务中心选择器 (100% 像素级对齐设计规范) */}
<div className="px-4 pt-6 pb-5 shrink-0 border-b border-white/15">
  {sidebarOpen ? (
    <div className="flex flex-col items-center">
      {/* 官方纯白矢量 LOGO */}
      <Link
        href="/"
        className="group focus:outline-none transition-transform hover:scale-[1.02]"
        title="特变电工能碳数字化双中心"
      >
        <img
          src="/logo-white.png"
          alt="TBEA 特变电工"
          className="h-[22px] w-auto object-contain mx-auto"
        />
      </Link>

      {/* 系统中文大标题 */}
      <div className="mt-4 text-center">
        <span className="font-bold text-[18px] tracking-[0.06em] text-white block leading-tight">
          {resolvedPlatformKey === 'carbon-footprint' ? '产品碳足迹集采中心' : '零碳园区集控中心'}
        </span>
        {/* 系统英文小字 (缩小字号，强制单行显示) */}
        <span className="text-[8px] font-medium text-white/75 block tracking-[0.1em] uppercase text-center mt-1.5 leading-none whitespace-nowrap">
          {resolvedPlatformKey === 'carbon-footprint' ? 'PRODUCT CARBON FOOTPRINT CENTER' : 'PARK CENTRALIZED CONTROL CENTER'}
        </span>
      </div>

      {/* 业务中心切换圆角胶囊下拉菜单 */}
      <div className="relative w-full mt-5" ref={dropdownRef}>
        <button
          type="button"
          onClick={() => setDropdownOpen((v) => !v)}
          className="flex w-full items-center justify-between rounded-xl border border-white/40 bg-white/10 hover:bg-white/15 active:bg-white/20 px-3.5 py-2.5 text-white transition-all cursor-pointer shadow-xs backdrop-blur-xs select-none"
          title="点击切换业务中心"
        >
          <div className="flex items-center gap-2.5 overflow-hidden">
            <Globe className="size-5 text-white shrink-0" strokeWidth={1.8} />
            <span className="text-[14px] font-medium text-white tracking-wide truncate">
              {resolvedPlatformKey === 'carbon-footprint' ? '产品碳足迹集采中心' : '零碳园区集控中心'}
            </span>
          </div>
          <ChevronDown className={cn('size-4 text-white/90 shrink-0 transition-transform duration-200', dropdownOpen && 'rotate-180')} />
        </button>

        {dropdownOpen && (
          <div className="absolute left-0 right-0 top-full z-50 mt-1.5 rounded-xl border border-slate-200 bg-white p-1.5 shadow-2xl animate-in fade-in-0 zoom-in-95 text-slate-800">
            {/* 业务中心切换选项列表 */}
          </div>
        )}
      </div>
    </div>
  ) : (
    /* 折叠态极简呈现 */
    <div className="flex flex-col items-center gap-3">
      <Link href="/" title="特变电工能碳数字化双中心">
        <Globe className="size-6 text-white hover:text-white/80 transition-colors" />
      </Link>
    </div>
  )}
</div>
```
