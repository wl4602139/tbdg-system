## 🏛️ 一、 规范与设计哲学

特变电工平台工程开发遵循 **“以集控中心为蓝本，工业实用主义、高信噪比、严格客观中立”** 的铁律：

1. **状态自解释**：通过边框高亮（`border-primary ring-2`）自然呈现激活状态，严禁添加“已选中”、“图表联动中”等过程说明标签；
2. **客观中立原则**：严禁在卡片、徽章或表格中出现“电能品质：优良”、“表现优异”、“落后单位”等定性评判或说教性评价，统一以时序对比（YoY 同比、MoM 环比、基准偏差量）与客观工况（运行中、待机、检修）表达；
3. **极简反冗余**：卡片与图表头部直接呈现核心数据，杜绝新手自述提示语；空状态统一采用单行干练结论（`暂无相关工序！`、`暂无相关产品！`、`暂无相关记录！`）；
4. **五大工业静态不变量**：
   - 表格行高强制 **`44px`**（`h-[44px]`）；
   - 主题科技蓝统一 **`#2C7CFF`**；
   - 导出按钮统一固定尺寸 **`80px × 36px`**，圆角 `8px`，背景 `#2C7CFF`，白字白图标；
   - 输入框与下拉选择框统一推荐宽度 **`200px`**，高度固定 **`36px`**，圆角 `8px`，描边 `#E2E8F0`；
   - 左侧导航栏固定 **`260px`**，拓扑树节点间距 **`30px`**，浅蓝激活底色 **`#EBF3FF`**。

### 1. 8 大能源介质官方标准色 (`ENERGY_MEDIA_TOKENS`)

| 介质 Key | 名称 | 标准色值 | 常用单位 | 业务场景 |
| :--- | :--- | :--- | :--- | :--- |

| `grid` | **市电量** | `#41C0FF` | kWh | 电网购入电量、市电供应占比 |
| `green` | **直供绿电量** | `#00D492` | kWh | 分布式光伏发电、绿电消纳率 |
| `water` | **水资源** | `#10C4CE` | t | 工业用水消耗、循环水监测 |
| `gas` | **天然气** | `#FF6536` | m³ | 窑炉天然气消耗、锅炉热力采样 |
| `steam` | **蒸汽** | `#FFBA00` | t | 外购蒸汽总量、工艺干燥固化（原管道工作压力） |

### 2. 4 段分时电量 (TOU) 标准色 (`TOU_PERIOD_TOKENS`)

- **尖峰 (`sharp`)**：`#FF6536`（警示橙红）
- **高峰 (`peak`)**：`#FFBA00`（活力金黄）
- **平段 (`flat`)**：`#2C7CFF`（稳健科技蓝）
- **低谷 (`valley`)**：`#10C4CE`（低谷青蓝）

### 2. 44px 工业高密数据表格与配套分页器 (DataTable & Pagination)

#### `DataTable` 表格组件
全站统一 44px 行高，垂直居中，支持列排序与 Mono 等宽数字对齐：
```tsx
import { DataTable } from '@/components/design-system'

const columns = [
  { key: 'code', label: '设备编号', align: 'left', sortable: true },
  { key: 'name', label: '设备名称', align: 'left' },
  { key: 'media', label: '主耗介质', align: 'center', render: (r) => <EnergyBadge media={r.media} /> },
  { key: 'value', label: '读数', align: 'right', sortable: true },
]

<DataTable columns={columns} rows={rows} />
```

#### `Pagination` 工业高密配套分页器
专为 44px 数据表格定制，高度 36px，8px 圆角，实心 `#2C7CFF` 高亮，支持每页条数切换与快速跳转：
```tsx
import { Pagination } from '@/components/design-system'

<Pagination
  currentPage={currentPage}
  totalItems={totalCount}
  pageSize={pageSize}
  pageSizeOptions={[10, 20, 50, 100]}
  onPageChange={setCurrentPage}
  onPageSizeChange={setPageSize}
/>
```

#### `ExportButton` 标准导出按钮
固定尺寸 `80px × 36px`，`#2C7CFF` 背景：
```tsx
import { ExportButton } from '@/components/design-system'

<ExportButton title="导出台账" onClick={handleExport} />
```

### 3. 标准工业模态弹窗 (`Modal`)

支持 `sm / md / lg / xl / 2xl / 3xl` 六档工业响应式最大宽度，自带 ESC 退出与 8px 圆角：

```tsx
<Modal

  footer={
    <>

    </>
  }
>
  <div className="space-y-4 py-2">
    {/* 复杂表单内容 */}
  </div>
</Modal>
```

## 🚀 四、 业务页面标准开发范式 (100% 工业规范)

```tsx
'use client'

import { useState } from 'react'
import {
  Panel,
  KpiCard,
  DataTable,
  Pagination,
  Modal,
  Button,
  ExportButton,
  Tabs,
  SearchInput,
  StandardSelect,
  Switch,
  Checkbox,
  EnergyBadge,
  BenchmarkIndicator,
  StatusBadge,
} from '@/components/design-system'
import { Zap, Flame } from 'lucide-react'

export default function BusinessDemoPage() {
  const [tab, setTab] = useState('month')
  const [search, setSearch] = useState('')
  const [currentPage, setCurrentPage] = useState(1)
  const [pageSize, setPageSize] = useState(10)
  const [isModalOpen, setIsModalOpen] = useState(false)

  return (
    <div className="space-y-6">
      {/* 1. 顶部指标栏 */}
      <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4">
        <KpiCard title="当日总电量" value="38,200" unit="kWh" delta="-3.5%" up={false} icon={Zap} />
        <KpiCard title="当日蒸汽消耗" value="280.5" unit="t" delta="+1.2%" up={true} icon={Flame} />
      </div>

      {/* 2. 主监控面板 */}
      <Panel
        title="在线设备用能明细"
        actions={
          <div className="flex items-center gap-2">
            <Button variant="outline" onClick={() => setIsModalOpen(true)}>配置规则</Button>
            <ExportButton title="导出" onClick={() => {}} />
          </div>
        }
      >
        <div className="flex flex-wrap items-center justify-between gap-3 mb-4">
          <Tabs
            value={tab}
            onChange={setTab}
            items={[
              { value: 'day', label: '日视图' },
              { value: 'month', label: '月视图' },
            ]}
          />
          <div className="flex items-center gap-3">
            <SearchInput value={search} onChange={(e) => setSearch(e.target.value)} />
            <StandardSelect
              options={[{ value: 'all', label: '全厂设备' }]}
            />
          </div>
        </div>

        {/* 44px 高密数据表格 */}
        <DataTable columns={columns} rows={pageRows} />

        {/* 标准工业分页器 */}
        <Pagination
          currentPage={currentPage}
          totalItems={120}
          pageSize={pageSize}
          onPageChange={setCurrentPage}
          onPageSizeChange={setPageSize}
        />
      </Panel>

      {/* 8px 圆角工业模态弹窗 */}
      <Modal
        open={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        title="设备运行规则配置"
        size="md"
      >
        <div className="space-y-4 py-2">
          <p className="text-sm text-muted-foreground">设置在线监测参数与告警阈值。</p>
        </div>
      </Modal>
    </div>
  )
}
```
