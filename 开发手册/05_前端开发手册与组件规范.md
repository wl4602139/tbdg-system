# 💻 前端开发手册与组件规范

## 1. 架构与工程规范
* **框架底座**：Next.js 16.3.0 (App Router) + React 19 + TypeScript 5.7+
* **样式方案**：Tailwind CSS 4.3 + CSS Variables Design Tokens
* **图标体系**：Lucide React
* **数据可视化**：Recharts 3.10 + ECharts 5.x（桑基图）

## 3. 组件 8 种核心状态实现矩阵
1. **Normal (正常态)**：石板灰背景，1px 细边框，字体清晰对比。
2. **Hover (悬停态)**：边框过渡到 `--color-primary` (200ms cubic-bezier)，Y轴向上微浮 2px。
3. **Active (激活/选中态)**：高亮主色背景微透，内发光 (Box-shadow glow)。
4. **Focus (键盘焦点 a11y)**：2px 科技蓝外轮廓 (`outline-offset: 2px`)。
5. **Loading (加载骨架态)**：带有脉冲流光 (Pulse Shimmer) 的 Skeleton 骨架屏。
6. **Disabled / Disabled-Park (置灰态)**：未接入的园区/工厂节点，透明度 50%，`cursor: not-allowed`，悬停显示 Tooltip “该工厂数据规划接入中”。
7. **Empty (空数据态)**：展示工业风缺省插画 + “暂无该周期量测数据，请检查网关或手动补录” 引导按钮。
8. **Error / Alert (超标异常态)**：红色柔和呼吸边框，指标数值伴随上下箭头差异标注。
