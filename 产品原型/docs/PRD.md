> 版本：v2.0（交互细化版）
> 范围：集控中心（集中监管 · 多维对标）＋ 集采中心（产品碳足迹 · 因子库）
> 对标依据：《“双中心”项目能碳管控指标体系 V1.4》《集采中心功能梳理 V1.0》《集控中心检测功能描述》《园区-工厂对应关系表》

## 1. 背景与目标

特变电工集团推进“双中心”（集控中心 + 集采中心）建设，目标是把分散在各园区、各经营单位的能源与碳数据集中起来，形成**面向集团领导层的管理对标工具**，让领导者“一眼看清”下属工厂与零碳工厂的差距，明确管理抓手。

- **集控中心**：关注工厂的**综合指标**，对园区/工厂进行集团内部管理与对标，落实管理抓手，量化各工厂与零碳工厂的差距。
- **集采中心**：采集各工厂生产产品的**产品碳足迹（PCF）**数据（工厂自有 PCF 核算系统，可直接取值），进行对比分析，并构建集团**自有因子库**。

### 1.1 核心设计原则（领导视角）

1. **宏观优先**：宏观指标的展示、对比设计得显眼，领导无需下钻即可获得判断。
2. **对标即抓手**：所有对比都指向“差距在哪、抓手在哪”，红色高亮标注差距最大的指标。
3. **多维可切换**：一套关键指标，在 5 个核心维度间自由对标，视角切换零成本。
4. **可追溯**：任何宏观结论都能下钻到指标原始数据、计算公式与变化曲线。

## 3. 指标体系（V1.4）

指标分三级，集控中心以**工厂整体**为主，向下钻取到产品与工序。

| 级别 | 说明 | 关键指标（示例） |
| --- | --- | --- |
| 工厂整体（工厂综合） | 面向集团管理对标的宏观指标 | 综合能源消费量、单位产值综合能耗、单位产值碳排放、绿电占比、非化石能源占比、总碳排放量 |
| 产品型号（产品整体） | 单位产品能耗/碳排 | 单位产品综合能耗、单位产品碳排放、**单位产品碳足迹(PCF)** |
| 关键工序（工序详情） | 工序级能耗 | 吨铜电耗、吨铝电耗、交联工序单耗、干燥/试验/退火单位电耗 |

### 3.1 零碳关键对标指标（对标视图采用的 5 项）

| key | 指标 | 单位 | 零碳标杆 | 生成基准 | 方向 |
| --- | --- | --- | --- | --- | --- |
| `unitEnergy` | 单位产品综合能耗 | kgce/台 | 400 | 430 | 越低越好 |
| `outputEnergy` | 单位产值能耗 | tce/万元 | 0.30 | 0.34 | 越低越好 |
| `unitCarbon` | 单位产品碳排放 | kgCO2/台 | 900 | 980 | 越低越好 |
| `greenRatio` | 绿电占比 | % | 60 | 52 | 越高越好 |
| `pcf` | 单位产品碳足迹 | kgCO2e/台 | 1000 | 1080 | 越低越好 |

### 3.2 计算口径（对标视图统一采用）

以下公式在 `lib/benchmark.ts` 中实现，是所有对标交互的数值基础。

- **达标系数** `achievement(v, m)`
  - 越低越好：`benchmark / v`
  - 越高越好：`v / benchmark`
  - 结果 `≥1` 表示已达到或优于零碳标杆。
- **距标杆差距** `gapPct(v, m)`（正=仍需改进的差距，负=已优于标杆）
  - 越低越好：`(v − benchmark) / benchmark × 100%`
  - 越高越好：`(benchmark − v) / benchmark × 100%`
- **单指标状态** `metricStatus`（依据达标系数 `a`）
  - `a ≥ 1.00` → **优秀**（已达标）
  - `0.85 ≤ a < 1.00` → **正常**（接近）
  - `a < 0.85` → **异常**（差距大）
- **零碳综合得分** `compositeScore`（0–100）
  - 对 5 项指标各取 `min(1.15, achievement)` 后求平均，再 `×86`，最后夹逼到 `[45, 99]`。
  - `min(1.15,…)` 用于**限制单项过度领先**对总分的拉动，避免一项极优掩盖其余短板。
- **综合得分状态阈值**（红黑榜与明细表统一）
  - `≥90` → 优秀（绿）；`78–89` → 正常（黄）；`<78` → 异常（红）。
- **同比 YoY**：正值=数值上升。着色按方向判定“是否在改善”：越低越好且下降 = 改善（绿）；越高越好且上升 = 改善（绿）；反之红；`|v|<0.5%` 视为持平（灰 + 减号图标）。

## 4. 集控中心 · 多维对标（本次核心）

> 路由：`/zero-carbon/monitor/benchmark`（集中监管四个独立子页之一）
> 组件：`components/monitor/benchmark-view.tsx`

### 4.1 页面状态与默认值

| 状态 | 默认值 | 取值 | 说明 |
| --- | --- | --- | --- |
| `dim`（对标维度） | `factory` | factory / line / category / model / plan | 决定红黑榜、卡片、趋势、明细表的口径 |
| `metricKey`（对标指标） | `score` | score / unitEnergy / outputEnergy / unitCarbon / greenRatio / pcf | `score`=零碳综合得分 |

- 两个状态相互独立，任一变化即联动刷新**全部**区块，无需刷新按钮。
- 顶部工厂筛选器（页面级 `PageHeader`）在本子页**隐藏**（对标视图自带维度切换，工厂筛选会造成语义冲突）。

### 4.2 维度切换（5 个核心维度）

按钮组，单选。选中态 = 主色实心 + 光晕（`bg-primary text-primary-foreground shadow`）；未选中 = 幽灵态，hover 变 `bg-accent`。

| 维度 | 对标含义 | 实体示例 | 特殊交互 |
| --- | --- | --- | --- |
| 工厂 | 不同工厂横向对标 | 天津变压器厂、衡阳电缆厂… | 项目公司置灰不排名 |
| 产线 | 同工厂/跨工厂产线对标 | 变压器总装线、交联电缆线… | — |
| 产品种类 | 不同产品种类对标 | 电力变压器、电力电缆… | — |
| 产品型号 | 同产线/跨产线型号对标 | SG10-2500kVA、YJV-8.7/15kV… | — |
| 生产计划 | **相同产品·不同时间批次**对标 | 2024 Q1…2025 Q1 批次 | `temporal=true`，右侧改为**减碳趋势折线**；维度描述追加“当前产品：SG10-2500kVA 变压器” |

> 维度说明文字实时显示在按钮组下方（`dimObj.desc`）。

### 4.3 指标切换

按钮组，单选，共 6 项：零碳综合得分 + 5 项关键指标（按钮显示 `short` 简称）。选中态 = `bg-primary/15 text-primary`。切换后：红黑榜排序依据、红黑榜数值列、条形比例尺、右侧趋势的对标线全部联动。

### 4.4 区块一 · 零碳关键指标总览（5 张卡片）

- 一行 5 卡（`xl:grid-cols-5`，中屏 3 列，小屏 2 列）。**恒定展示全部 5 项指标**，不随 `metricKey` 变化（用于“任何时候都能看到 5 项体检结果”）。
- 每卡取值 = 当前维度下**所有实体在该指标的平均值**。
- 卡片元素：指标名 + 状态徽章（优/正常/异常三色）；超大等宽数值 + 单位；零碳标杆值；右侧“已达标/差 N%”。
- **达标度进度条**：宽度 = `min(100, achievement/1.2 × 100)%`；标杆刻度竖线固定在 `1/1.2 ≈ 83.3%` 处（即条形越过该竖线即达标）；条色随状态三色。

### 4.5 区块二 · 领导视角宏观概要（4 ���大卡片）

| 卡片 | 内容 | 计算/交互规则 |
| --- | --- | --- |
| **平均零碳得分** | 当前维度平均分 `/100` | 超大主色数字 + 光晕；副文案固定“零碳标杆线 90 分”；带科技径向底纹 |
| **达到零碳标杆** | 达标实体数 `/总数` | 达标 = 综合得分 `≥90`；下方进度条 = `reachCount/total` |
| **标杆对象** | 得分最高实体 | 绿色边框卡；显示名称 + 综合得分 + “全组领先”；名称过长省略并 `title` 提示 |
| **管理抓手** | 得分最低实体 + 其最大差距指标 | 红色边框卡；抓手指标 = 该实体 `gapPct` 最大的指标；显示“主要差距：X 距标杆 +N%” |

> **管理抓手判定**：先按综合得分取最差实体，再在该实体 5 项指标中取 `gapPct` 最大者，直接点名“抓什么”。

### 4.6 区块三 · 对标红黑榜（横向条形排名）

左宽右窄双栏（`xl:grid-cols-[1.4fr_1fr]`），左为红黑榜。

**排序规则**（`rankByMetric`）：
- `metricKey=score`：综合得分**降序**。
- 越低越好指标：数值**升序**（越小越靠前）。
- 越高越好指标：数值**降序**（越大越靠前）。
- 排名从 1 开始；前 3 名序号徽章配金/银/铜色（`#F5C451/#C9D1D9/#CD8B62`），其余为中性灰。

**单行元素**：排名徽章 · 实体名 + meta（小屏隐藏 meta）· 数值(等宽)+单位(无衬线，避免缺字) · 同比箭头（`score` 时不显示）· 条形 · 右侧“达标/+N%”。

**条形比例尺**：
- `score`：`min(100, value/108 × 100)%`；标杆竖线固定 `1/1.2` 处。
- 指标：`min(100, achievement/1.2 × 100)%`；标杆竖线同上。
- 条色随该行状态三色；竖线为 `foreground/60`，`title="零碳标杆"`。

**图例**（底部）：优秀·达标（绿）/ 正常·接近（黄）/ 异常·差距大（红）/ 零碳标杆线（竖线）。

### 4.7 区块四 · 右侧趋势/结构

- **生产计划维度（temporal）且非 score**：显示“相同产品·减碳趋势”折线 —— X=批次时间(meta)，一条为该指标实测值、一条为零碳标杆恒定线，直观看出逐批是否收敛到标杆。
- **其他情况**：显示“综合得分分布”折线 —— X=实体 meta，一条综合得分、一条标杆线 90。

### 4.8 区块五 · 多指标对标明细表

- 行 = 当前维度全部实体（**固定按综合得分降序**，与上方红黑榜的指标排序解耦，保证表格稳定可读）。
- 列 = 排名 · 实体(名+meta) · 综合得分 · 5 项关键指标。
- 综合得分按 `90/78` 阈值三色；每个指标单元格 = 数值 + `gapPct`（达标显“达标”，否则 `+N%`），文字按单指标状态三色。
- **管理抓手高亮**：每行 `gapPct` 最大的指标单元格加 `bg-destructive/10` 红底，即该实体优先改进项。
- 表尾说明 + “可下钻至指标管控查看原始数据与计算说明”指引。

### 4.9 响应式与空态

- 维度/指标按钮组超宽时横向滚动（`overflow-x-auto`），不换行挤压。
- 卡片网格断点：`grid-cols-2 → md:3 → xl:4/5`。
- 演示数据恒有值，无空态；接真实数据时约定：实体无数据则灰显“—”、不计入平均与排名。

## 6. 集采中心 · 功能设计（对齐原型 V4.0）

面向各工厂生产**产品碳足迹（PCF）**的收集、对比与集团自有因子库建设。工厂拥有自己的 PCF 核算系统，集采中心**直接收集 PCF 值**再对比建库，不重复核算。

### 6.0 特变电装业务级联（贯穿全部分析页）

数据模型 `lib/procurement.ts`。级联链：`产业 → 产线 → 产品类别 → 产品型号 → 经营单位 → 销售订单 → 生产计划(批次)`。

| 层级 | 示例 |
| --- | --- |
| 产业 | 变压器、电线电缆、高压开关 |
| 产线（产业内） | 变压器：高压产线 / 中低压产线 / 干式产线 |
| 产品类别 | 电力变压器、干式变压器、箱式变电站… |
| 产品型号 | SFZ11-110、S13-M-800、YJV22-8.7/15… |
| 经营单位 | 衡变本部、沈变本部、新疆特变…（**项目公司置灰、不参与对标**） |
| 生产计划 | 同型号不同批次（PL-260710-01…），支撑“同型号不同时间生产”对比 |

**特征量（feature）**：变压器按 `kVA`、电缆按 `km`、开关按 `台/间隔`，单位产品碳足迹以 `kgCO2/特征量` 表达，保证跨型号可比。

### 6.1 横向对比（`/analysis/compare`）

> 场景：同一产品型号，在不同经营单位之间比谁碳足迹低。

- **级联筛选器**：产业/产线/类别为 `Select`，**产品型号为可搜索 `ComboBox`**（支持模糊搜索）；上级变更时逐级重置下级到首项。
- **重点指标区**：3 张 `KpiCard`（对比经营单位数、生产总数、单位产品碳足迹均值）。
- **主对比图**：`BarBenchmark` 横向对比各经营单位单位产品碳足迹，**基准线为虚线**，超基准柱标红（`--destructive`），达标柱主色。
- **经营单位排名表**：按单位产品碳足迹升序；第 1 名挂 `Award` 标杆徽标；**项目公司行置灰**且不计入排名序号；每行右侧“下钻”。
- **下钻弹窗（Modal）**：标题=型号+经营单位；内容含①生命周期构成 `Donut`（原材料/生产/运输…）②主材碳排条形③工序碳排条形④该单位该型号的**销售订单列表**（客户/数量/单台 tCO2/拆分生产计划标签）。底部“碳足迹详情”跳 `实景数据库/碳足迹核算`。

### 6.2 纵向对比 · 红黑榜（`/analysis/ranking`）

> 场景：按组织范围，对同类别各型号做红黑榜，锁定改进对象。

- **左侧经营单位组织树**：`集团 → 板块 → 经营单位`，可展开/收起；项目公司置灰；点击切换 `scope`（默认“全部经营单位”=跨单位均值）。
- **级联筛选**：产业/产线/类别/时间。
- **重点指标区**：3 张 `KpiCard`（型号数量、生产总数、单位产品碳足迹均值，随 scope 重算）。
- **红榜 Top5 / 黑榜 Top5**：型号按单位产品碳足迹升序，前 n 入红榜（低碳标杆、`--success` 顶边），后 n 入黑榜（改进对象、`--destructive` 顶边）；红榜第 1 挂 `Award`、黑榜第 1 挂 `TriangleAlert`。
- **点击榜单卡片下钻（Modal）**：`各生产计划单台碳足迹对比` 条形（**同型号不同生产计划=不同时间生产的横向对比**）+ 销售订单及拆分生产计划表。

### 6.3 基准对比（`/analysis/benchmark`）

> 场景：以车间/产线为对象，看单台、主材、生产环节碳排与基准的差距，识别高碳热点。

- **级联筛选** + **`基准值设置` 按钮**（右上，`Settings` 图标）。
- **三联基准图**：`单台产品碳足迹 / 主材碳排 / 生产环节碳排`，各为 `BarBenchmark`（横轴=车间产线、虚线=基准、超基准标红）；顶部“对比范围”可切全部/单产线。点击柱→车间明细。
- **车间产线碳排汇总表**：各车间三项指标 + 状态徽标（达标/接近/超标 三色）；点击行看全维度基准对比。

## 7. 交互与视觉规范（全局）

- **信息层级**：宏观大卡片（超大数字 + 标杆线）> 红黑榜（排名+条形）> 明细表（多指标+抓手高亮）。
- **颜色语义**：主色（品牌绿）达标/正向；`--destructive` 红仅用于“差距/抓手/异常”；`--warning` 黄为“接近/正常”。全站 3–5 色。
- **配色令牌**：状态色统一走 `var(--success) / var(--warning) / var(--destructive)`，禁止硬编码。
- **字体**：数字用等宽体（`font-mono`）强化可比性；**中文单位强制 `font-sans`**（等宽字体缺 CJK 字形会显示豆腐块）。
- **同比表达**：升/降箭头结合方向判定正负着色，避免“下降=坏”的误读。
- **可下钻**：对标 → 指标管控 → 指标二级详情（原始数据/曲线/公式），保证可追溯。
- **导航**：二级菜单为独立页面（非页内 Tab）；页面顶部不显示模块名/描述，仅面包屑 + 功能性筛选器。
