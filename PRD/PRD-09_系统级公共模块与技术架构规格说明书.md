# 【PRD-09】系统级公共模块与技术架构规格说明书

> **文档受控编号**：`TBEA-PRD-MASTER-2026-VOL-09`  
> **标准 NAV-ID**：`NAV-SYS-USER`、`NAV-SYS-ROLE`、`NAV-SYS-FLOW`、`NAV-SYS-ALM`、`NAV-SYS-AUDIT`  
> **基线版本**：Release v1.2.0 (生产基线版)  

---

## 一、 统一数据库架构与时序降采样

- **PostgreSQL 16**：主数据、BOM、权限、工作流；
- **TimescaleDB**：工业高频时序遥测，时序分层降采样（原始秒级保留 7 天 ➔ 1 分钟保留 90 天 ➔ 1 小时保留 3 年 ➔ 日汇总永久留底）；
- **Redis 7.2**：缓存与 100ms 提交防刷分布式锁（Redlock）。

---

## 二、 信创国产化平替与国密算法 (SM2/SM3/SM4)

- **信创四层平替**：鲲鹏920/海光C86 CPU + 统信UOS/银河麒麟 Server + openGauss 5.0/人大金仓 KingbaseES + 东方通 TongWeb；
- **国密算法体系**：传输层支持 TLCP/TLS 1.3；数据落盘敏感字段 SM4 加密；电子签章 SM2 非对称算法；防篡改存证 SM3 杂凑摘要。

---

## 三、 公共中枢模块规格

1. **RBAC 四维矩阵**：涵盖 P1~P6 角色，明确 P1 拥有全域只读大盘 + 终审签章特权；
2. **工作流引擎**：支持多级会签、或签、超时 48h 自动催办；
3. **统一告警中心**：监听电压偏差 ±7%、油温越限、防逆流异常，支持短信/企微/钉钉分级秒推；
4. **附件管理 (MinIO)**：集中存储 PDF 证书、检测报告，强制哈希指纹校验；
5. **审计日志**：操作全流程 SHA-256 链式 Hash 记录，防止单方篡改；
6. **双因素认证 (2FA)**：高管终审与对外签发强制动态验证码。\n
