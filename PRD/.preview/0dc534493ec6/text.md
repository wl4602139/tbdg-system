第一章 顶层业务架构与标准规范

一、项目背景与建设目标

1. 项目建设背景

宏观战略与集团“十五五”低碳发展要求在国家“碳达峰、碳中和”战略深入推进的宏观背景下，工业装备制造业正加速向全生命周期绿色化、数字化转型。特变电工电装集团作为我国输变电高端装备制造领域的龙头企业，坚决贯彻集团绿色低碳发展统一部署。根据集团“十五五”战略规划纲要，到2028年，电装集团须全面形成以“零碳园区、零碳工厂、零碳产品”为主线的绿色高质量发展模式，确保零碳园区全面建成并成为集团新的核心产业增长极。在此目标引领下，构建一套覆盖自身运营并向上下游产业链纵深辐射、具备高公信力与高效协同能力的碳足迹数字化管理生态系统，已成为支撑集团战略落地的关键路径。

国际贸易绿色壁垒与合规实质性倒逼随着全球绿色供应链竞争加剧，欧盟碳边境调节机制（CBAM）已进入实质性操作阶段，针对输变电产品及其原材料（钢、铝等）的直接与间接排放溯源监管日益严苛。电装集团产品大量服务于国内外重点工程及海外基础设施建设，亟需建立符合国际核算标准（如ISO 14067、GHG Protocol等）、支持全流程证据链追溯与多维溯源的产品碳足迹认证体系，打破国际绿色贸易壁垒，巩固全球竞争优势。

数字化能碳运营现状与核心痛点当前，电装集团绿色转型已进入深水区，但数字化支撑与集约化管控层面仍存在显著瓶颈：

能碳数据底座割裂，缺乏统一监管抓手： 集团下辖18个生产基地/园区所处区域广泛、生产工艺与用能结构各异，各单位能源计量统计口径、数据精度及碳排放管控标准不一致，数据孤岛严重，总部层面难以实现“一本账”穿透式监管和精准横向对标。

零碳评价无标可依，成效难以量化评估： 零碳园区建设缺乏统一、标准化的指标评价框架与动态打分体系，各单位降碳举措分散、效果参差不齐，难以形成可复制、可推广的绿色制造示范模式。

碳足迹核算成本高、周期长、证据链缺失： 传统的碳足迹核算高度依赖离线调研与第三方机构人工驻场，数据收集周期动辄数月，认证成本居高不下；且过程数据缺乏原始采样凭证与不可篡改的时间戳支撑，权威性易受质疑。

云边端协同能力薄弱，缺乏实时闭环调控： 现有系统多停留在“事后统计与静态展示”，边缘侧缺乏智能化数据采集、边缘计算与闭环控制机制，无法实现供能、储能、用能多要素的微秒级与秒级协同优化。

建设目标

本项目旨在通过“软硬件一体、云边端协同、管服一体化”的整体建设路径，研发构建“工厂—产业单位—总部”三级贯通的零碳集控运营系统与产品碳足迹集采管理认证一体化平台，实现对能源与碳排放“精准化计量、精细化管控、智能化决策、可视化呈现”，具体目标涵盖三个层面与四大维度：

管理层级落地目标

集团总部层（监管与决策中心）： 打造集团能碳数据“驾驶舱”与统管枢纽，全面接入并统一管理18个园区的能碳运行态势。建立健全集团级能效对标体系与零碳园区评估模型，实现能耗异常穿透分析、减碳潜能挖掘与绿色转型成效的权威对外呈现。

产业单位层（协同与治理中心）： 固化标准化的碳足迹数据采集、因子匹配与全过程核算流程，构建面向变压器、电缆、高低压开关等重点装备的行业级实景数据库（LCI），指导下属各生产经营单位科学编制降碳规划并精准落地技改措施。

工厂车间层（执行与核算中心）： 沉淀标准因子集、计算模型规范及一键式认证申报模板等数字化工具包，配合边缘网关与控制器实现产线级与设备级数据自动采集，支撑各工厂快速响应客户低碳招投标与第三方合规认证需求，核算效率提升50%以上。

系统核心能力目标

计量精准化： 依托工业物联网架构与边缘调控一体机，打通产线DCS、SCADA、能源表计等系统，消除数据盲区与统计偏差，实现核心能碳指标毫秒级/秒级高精度感知。

管控精细化： 建立覆盖原材料输入、生产加工、组装测试到包装出厂的装备产品全生命周期（Cradle-to-Gate）碳足迹追踪链路，形成不可篡改的碳排放数据追溯链。

决策智能化： 深度融合行业机理与AI优化算法，实现用能负荷精准预测、峰谷分时响应、多能互补协同调度与碳减排路径智能推荐。

呈现全景化： 打造集管控、运营、汇报于一体的3D/多维数字化大屏，以生动图表与动态全景呈现集团双碳目标推进路径。

建设范围

本项目建设范围涵盖技术服务（标准与咨询）、软件研发、系统集成与数据治理、实施交付、硬件研制及供货部署五大板块，全面实现软硬件交钥匙工程。

技术服务范围（咨询、标准与数据体系研究）

能碳与园区管理标准构建： 深入结合输变电制造行业工艺特征，完成特变电工电装集团零碳园区集控中心管理标准研制；梳理零碳园区、零碳工厂评价指标体系，形成分级评价准则与对标评估方案。

产品碳足迹规范与管理体系： 编制输变电装备（涵盖变压器、线缆、开关设备）碳足迹核算导则与管控规范，明确生命周期边界（系统边界、分配原则、截止准则等），研究符合CBAM政策及主流国际标准（ISO 14067）的实景数据采集与证据链管理体系。

标准数据字典与接口规范梳理： 制定集团统一度量衡的能碳物联数据字典、多源异构系统数据交互协议规范，梳理并设计集控中心与集采中心的核心API标准接口规范。

装备制造专属因子库体系梳理： 系统化完成变压器、线缆、开关等主营产品的上下游物料基础背景数据库梳理，梳理电力消耗、化石燃料、原材料专属因子集，支撑平台快速算碳。

- 6 项对标指标：零碳综合得分 + 5 项关键指标（单位产品综合能耗、单位产值能耗、单位产品碳排放、绿电占比、单位产品碳足迹）；

零碳关键对标指标基准（V1.4）：

- 单位产品综合能耗：零碳标杆 400 kgce/台，生成基准 430；单位产值能耗：0.30 / 0.34 tce/万元；

- 单位产品碳排放：900 / 980 kgCO2/台；绿电占比：60 / 52 %（越高越好）；单位产品碳足迹：1000 / 1080 kgCO2e/台；

计算口径（lib/benchmark.ts 实现，供研发核对）：

- 达标系数 achievement：越低越好 = 标杆/实测，越高越好 = 实测/标杆，≥1 即达到或优于标杆；

- 距标杆差距 gapPct：越低越好 = (实测−标杆)/标杆×100%，越高越好 = (标杆−实测)/标杆×100%；

- 单指标状态：达标系数 ≥1.00 优秀，0.85~1.00 正常，<0.85 异常；

- 零碳综合得分（0~100）：对 5 项指标各取 min(1.15, 达标系数) 后求平均，再 ×86，夹逼到 [45, 99]（min 上限用于限制单项过度领先）；

- 综合得分三色阈值：≥90 优秀（绿），78~89 正常（黄），<78 异常（红）；

页面区块与联动：

- 总览 5 卡：恒定展示全部 5 项指标（不随所选指标变化），每卡含状态徽章、超大数值、标杆值、“已达标 / 差 N%”与达标度进度条（标杆刻度竖线固定 83.3% 处）；

- 宏观概要 4 卡：平均零碳得分、达到零碳标杆（达标=综合得分 ≥90）实体数 / 总数、标杆对象（得分最高实体）、管理抓手（得分最低实体 + 其 gapPct 最大的指标，直接点名“抓什么”）；

- 对标红黑榜：横向条形排名，score 降序、越低越好升序、越高越好降序；前 3 名序号徽章金 / 银 / 铜，其余中性灰；条形比例尺 = min(100, achievement/1.2×100)%，标杆竖线固定 1/1.2 处；

支持按批次号追踪同一产品历年碳足迹演变趋势，提供原材料替代（如高磁感取向硅钢片替代传统硅钢）、绿电消纳提升及工艺优化对碳排变动的敏感性归因瀑布图。

交互与展示规则（源自 docs/PRD.md §6.2）：

- 左侧经营单位组织树：集团 → 板块 → 经营单位，可展开 / 收起；项目公司置灰；点击切换 scope（默认“全部经营单位”= 跨单位均值）；

- 级联筛选：产业 / 产线 / 类别 / 时间；

- 重点指标区：3 张 KpiCard（型号数量、生产总数、单位产品碳足迹均值，随 scope 重算）；

- 红榜 Top5 / 黑榜 Top5：型号按单位产品碳足迹升序，前 n 入红榜（低碳标杆），后 n 入黑榜（改进对象）；红榜第 1 挂 Award、黑榜第 1 挂 TriangleAlert；

- 点击榜单卡片下钻（Modal）：各生产计划单台碳足迹对比条形（同型号不同生产计划 = 不同时间生产的横向对比）+ 销售订单及拆分生产计划表；

- 场景定位：按组织范围对同类别各型号做红黑榜，锁定改进对象。

3. 基准对比分析

业务逻辑：以车间 / 产线为对象，看单台、主材、生产环节碳排与基准的差距，识别高碳热点（源自 docs/PRD.md §6.3 与《集采中心功能梳理 V1.0》“基准管理分析”）。

交互与展示规则：

- 级联筛选 + “基准值设置”按钮（右上，Settings 图标）；

- 三联基准图：单台产品碳足迹 / 主材碳排 / 生产环节碳排，各为 BarBenchmark（横轴 = 车间产线、虚线 = 基准、超基准标红）；顶部“对比范围”可切全部 / 单产线；点击柱 → 车间明细；

4. 碳热点分析与模拟

业务逻辑（源自《集采中心功能梳理 V1.0》“碳热点分析与模拟”）：

- 依据生产环节及原材料主材自动生成碳足迹构成饼图 / 柱状图，识别排放热点（贡献度排序、帕累托分析）；

- 情景模拟：支持“原材料替换”（如再生铜替代原生铜，单台产品碳足迹减少 Y%）、“绿电接入”等场景的减排潜力模拟，辅助低碳技术选型；

- 模拟结果对比：基准情景 vs 模拟情景碳足迹差额与减排率，可保存为模拟方案并纳入报告附件；

- 【待补充】模拟参数项（替换料因子、绿电比例、工艺节拍）由项目组确认。
