#### 【5】核心数学模型与算法框架

```math
Q_actual = ( Meter_end - Meter_start ) × Ratio        实物消耗量 =（止码 − 起码）× 倍率
E_tce = Q_actual × k_media                            折标煤量 = 实物量 × 介质折标系数
Q_peak_ratio = Q_peak / ( Q_tip + Q_peak + Q_flat + Q_valley ) × 100%
Rate_load = P_actual / P_rated × 100%                 负荷率
Alert_200 = ( Q_t - Q_{t-1} ) / Q_{t-1} > 200%        突增告警判定
```

**变量定义与取值约定：** `Meter_start / Meter_end` 为周期起止表底数；`Ratio` 为互感器变比倍率；`k_media` 为该介质折标准煤系数；`P_rated` 为设备额定功率；突增告警阈值 200% 为固定业务铁律。

#### 【6】展示、对标与判定口径

- **介质自适应铁律**：非电介质页面严禁出现任何峰平谷相关字样或图表元素。
- **对比口径**：非电介质右侧走势图必须叠加额定工艺基准线，以偏差量呈现而非主观评语。
- **单位口径**：电力以 kWh、水以 m³、蒸汽以 t、天然气以 m³、油以 L、液氮以 m³ 为统一实物单位，折标统一为 tce。
- **采样口径**：15 分钟为默认采样频率；历史区间查询走日结库，实时曲线走时序库。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 遥测心跳超 5 秒未响应：触发 `E_IO_MQTT_TIMEOUT`，图表展示最近一次缓存读数并打"数据延迟"微标签。
> - 边缘一体机断网：触发 `E_IO_GATEWAY_OFFLINE`，启动本地断点续传，恢复后自动补传，补传数据标注为"补传"。
> - 实物消耗量突增超 200%：触发告警中心事件并在卡片红框高亮，但**不得阻断数据入库**。
> - 未接入单位：路径置灰禁用，点击无响应且不弹出任何解释文案。
> - 除零兜底：占比类图表分母为 0 时显示 `--`，严禁 NaN。

#### 【5】核心数学模型与算法框架

```math
P_active = √3 × U × I × cosφ / 1s采样                     实时有功功率

Load = ( P_actual / P_rated ) × 100%                   设备负荷率
Load_MoM = ( Load_t - Load_{t-1} ) / Load_{t-1}        负荷率环比变动
Q_steam = ∫ F_instant dt                                蒸汽消耗量 = 瞬时流量时间积分
```

**变量定义与取值约定：** `P_rated` 为设备铭牌额定功率；`F_instant` 为瞬时蒸汽流量；告警阈值：负荷率超 120%、功率因数低于 0.90 触发越限。

#### 【5】核心数学模型与算法框架

```math
P_active = √3 × U × I × cosφ / 1s采集               实时有功功率
Load = ( P_actual / P_rated ) × 100%                 设备负荷率
Load_MoM = ( Load_t - Load_{t-1} ) / Load_{t-1}      负荷率环比变动
R_green = E_self_use / E_pv_gen × 100%               绿电消纳率
Q_steam = Σ ( F_instant × Δt )                       蒸汽消耗量时间积分
SOC_t = SOC_0 + ∫ ( P_charge × η_c ) dt / Cap_rated  荷电状态积分模型
```

**变量定义与取值约定：** `E_self_use` 为光伏自发自用电量；`E_pv_gen` 为光伏总发电量；`η_c` 为充电效率；`Cap_rated` 为储能额定容量。

#### 【6】展示、对标与判定口径

- **对比口径**：统一使用环比（MoM），不使用同比，避免季节性光照差异干扰判断。
- **绿电消纳口径**：绿电消纳率仅统计物理可溯源的自发自用量，不含绿证核销的等效量。
- **时段口径**：谷充峰放执行时段严格对齐能源价格管理模块最新生效的分时电价版本。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 储能 SOC 越界（<5% 或 >95%）触发告警并在卡片标注，不做自动干预控制。
> - 光伏夜间无出力：曲线自然归零，不显示"设备异常"等误判文案。
> - 实时点位超时：触发 `E_IO_MQTT_TIMEOUT`，展示缓存读数并打"数据延迟"微标签。
> - 设备未接入：节点置灰禁用，无解释性文案。

### 6. 能源碳排放监测

#### 【1】定位与架构角色

- **功能定位**：依据温室气体核算体系标准，按日/按月核算全厂化石能源直接燃烧与外购电力热力的二氧化碳排放量与强度走势，是碳排报表与 CBAM 申报的底数来源。
- **承载角色**：园区碳资产核算员 (P4)、P2 园区能碳专员。
- **页面路由**：`/monitor/carbon/emission`。
- **上游依赖**：用能在线监测介质消耗量、碳排放因子库（电网因子、燃料因子）、绿电交易凭证。
- **下游输出**：碳排报表、CBAM 申报底数、零碳工厂自评估温室气体维度数据。

#### 【2】业务场景与用户故事

- **业务场景**：依据温室气体核算体系标准，按日/按月核算全厂化石能源直接燃烧与外购电力热力的二氧化碳排放量与强度走势。
- **用户故事**：
  - As a **园区碳资产核算员 (Persona P4)**，
  - I want **实时掌握企业范围一与范围二碳排放量、万元产值碳排强度**，
  - So that **我能为集团减排规划与应对地方发改委碳履约提供合规依据**。

#### 【3】功能规格与交互契约

- **范围一与范围二双轴堆叠面积图**：Scope 1（直接排放：天然气、柴油、汽油燃烧）；Scope 2（间接排放：网购电力、外购蒸汽）。两范围以堆叠面积呈现，游标同步读取两层数值。
- **碳排放强度 KPI 卡片**：万元产值碳排放强度 (tCO2/万元)、单位产品碳排放强度 (tCO2/单位产品)。
- **绿电抵扣对比区**：输出抵扣前 / 抵扣后双柱对比，明确展示绿电占比与抵扣量。
- **因子版本标注**：图表底部常驻显示本次核算所用排放因子版本号与生效日期，支持点击查看因子来源。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 核算来源与约束规则 |
|:---|:---|:---|:---|:---|
| 1 | 化石燃料燃烧排放 | Decimal | tCO2e | $Σ(燃料消耗量 × 低位热值 × 碳含量 × 氧化率 × 44/12)$ |
| 2 | 购入电力间接排放 | Decimal | tCO2e | 外购电量 × 区域电网排放因子 |
| 3 | 购入热力间接排放 | Decimal | tCO2e | 外购蒸汽量 × 热力排放因子 |
| 4 | 总碳排放量 | Decimal | tCO2e | Scope 1 + Scope 2，≥ 0 |
| 5 | 万元产值碳排强度 | Decimal | tCO2e/万元 | 分母产值为 0 时显示 `--` |
| 6 | 单位产品碳排强度 | Decimal | tCO2e/单位 | 分母产量为 0 时显示 `--` |
| 7 | 绿电抵扣量 | Decimal | tCO2e | 绿电消纳量 × 电网排放因子 |
| 8 | 抵扣后净排放量 | Decimal | tCO2e | 总排放量 − 绿电抵扣量 |
| 9 | 排放因子版本号 | String | — | 因子库当前生效版本，过期因子拦截 |
| 10 | 核算口径标识 | Enum | — | 取值 `Scope 1` / `Scope 2` / `合计` |

#### 【5】核心数学模型与算法框架

```math
C_scope1 = Σ ( FC_i × NCV_i × CC_i × OF_i × 44/12 )      化石燃料燃烧直接排放
C_scope2 = Q_grid × EF_grid + Q_heat × EF_heat          外购电力与热力间接排放
C_total = C_scope1 + C_scope2                            总碳排放量
I_output = C_total / G_output × 10000                    万元产值碳排强度
C_net = C_total - E_green × EF_grid                      绿电抵扣后净排放量
```

**变量定义与取值约定：** `FC_i` 为第 i 种燃料消耗量；`NCV_i` 为低位热值；`CC_i` 为单位热值含碳量；`OF_i` 为碳氧化率；`EF_grid` 为区域电网排放因子（tCO2/MWh）；`EF_heat` 为外购热力排放因子；`E_green` 为绿电消纳量。

#### 【6】展示、对标与判定口径

- **核算口径**：严格区分 Scope 1 与 Scope 2，不得合并为单一数值对外发布。
- **因子口径**：排放因子取因子库当前生效版本，过期因子触发 `E_VAL_FACTOR_EXPIRED` 拦截。
- **抵扣口径**：绿电抵扣按具备物理可溯源条件的消纳量核算，绿证核销的等效量单独列示不混入。
- **强度口径**：万元产值碳排强度分母为当期产品产值（万元），与单位产值能耗口径保持一致。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 排放因子过期：触发 `E_VAL_FACTOR_EXPIRED`，图表底部标注"因子待升级"并保留历史版本可查。
> - 分母产值为 0：强度指标显示 `--`，严禁 NaN 或白屏。
> - 绿电抵扣量大于总排放量：按 0 兜底并标注"抵扣量异常，待核对凭证"。
> - 数据修复：已关账月度的碳排放数据禁止直接修改，须走特批反冲流程。
