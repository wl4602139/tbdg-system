#### 【5】核心数学模型与算法框架

```math
Ach_kpi = KPI_actual / KPI_target × 100%                  北极星指标达成率
Star_Level = f( Score_total )                            星级 = 按综合得分区间映射
Score_total = clamp( AVG( min(1.15, Ach_i) ) × 86, 45, 99 )   零碳综合得分
Handgrip = ARGMAX_i ( gapPct_i )                          管理抓手 = 偏差率最大指标
```

**变量定义与取值约定：** `Ach_i` 为 5 项关键指标各自的达标系数；`min(1.15, Ach_i)` 上限用于限制单项过度领先对总分的稀释；`gapPct_i` 为第 i 项指标距标杆的百分比差距。

#### 【6】展示、对标与判定口径

- 达成率 ≥100% 判定为达标（绿色），90%~100% 为接近（黄色），<90% 为滞后（红色）。
- 星级的四档阈值为固定铁律，不允许按园区自定义。
- 异常督办清单排序口径：先按综合得分升序，同分再按 gapPct 降序。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 目标值缺失的指标卡整卡输出"目标值待下发"，严禁显示 0% 或 NaN。
> - 批示提交采用幂等 Token，100ms 内重复提交触发 `E_SYS_CONCURRENCY_LOCK`。
> - 决策层账号须执行高管双重鉴权，展示界面对 L4 级数据强制叠加全屏防截屏水印。

#### 【5】核心数学模型与算法公式

```math
E = Σ ( E_i × k_i )                              综合能源消费量（GB/T 2589-2020 当量值）
C = C_burn + C_grid + C_heat                     总碳排放量 = 燃烧 + 购入电 + 购入热
C_grid = Q_grid × EF_grid                        购入电力排放 = 外购电量 × 区域电网因子
I = C / E                                        单位能耗碳排放
e_unit = E / M                                   单位产品综合能耗（分母按产业隔离）
R_media = R_j / Σ R_n × 100%                     占比类指标：分子分母先加总后再计算占比
Ach = 越低越好 ? (Benchmark / Actual) : (Actual / Benchmark)   达标系数
gapPct = 越低越好 ? ((Actual − Benchmark)/Benchmark×100%) : ((Benchmark − Actual)/Benchmark×100%)
```

**变量定义与取值约定：** `k_i` 为第 i 种能源折标准煤系数（tce/单位）；`EF_grid` 为园区所在地省级电网平均排放因子（tCO2/MWh）；`Ach ≥ 1.00` 判定优秀，`0.85 ~ 1.00` 判定正常，`< 0.85` 判定异常。

#### 【6】展示、对标与判定口径

- **聚合口径铁律**：**绝对量类指标**（能耗、碳排）按下级工厂数值直接汇总；**占比类/单耗类指标**必须先汇总分子分母再重新计算，严禁对各下级占比直接求平均。
- **对比口径**：同比变化以箭头 + 三色表达（绿：下降 / 红：上涨 / 灰：持平）；单位产品指标环比固定为同型号对比。
- **三色判定阈值**：达标系数 ≥1.00 优秀，0.85~1.00 正常，<0.85 异常。
- **空值口径**：任何无有效数据的指标位统一显示 `--`，并支持悬停查看"数据未上报"说明。
- **口径留痕**：每张卡片右下角可悬停查看本次核算所用的指标口径版本与折标系数版本。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - **除零安全兜底**：分母（产量、产值、增加值、总用电量）为 0 时，所有单耗类指标统一显示 `--`，触发 `E_CALC_UNIT_DIV_ZERO_SOFT`；严禁抛出 `NaN`、`Infinity` 或白屏。
> - **产业分母隔离铁律**：变压器与线缆单耗在数据库结构、底层 API 响应、页面表格及导出文件中绝对禁止混编在同一统计列，禁止跨产业直接对比。
> - **无工序单位判空**：选中 10 家无工序单位时，工序管控区域整行单行输出"暂无相关工序！"，触发 `E_QM_WHITE_LIST_MISS`。
> - **越权拦截**：P3 车间填报员访问集团级指标详情触发 `E_AUTH_RBAC_FORBIDDEN`。
> - **锁账拦截**：已关账月度指标详情页禁止触发任何重算动作，触发 `E_SYS_ENTRY_ALREADY_LOCKED`。
> - **因子过期**：指标核算所引用的折标系数或排放因子已过有效期时触发 `E_VAL_FACTOR_EXPIRED`，卡片标注"因子待升级"。

#### 【5】核心数学模型与算法框架

```math
Value_kpi = Numerator / Denominator                       指标值 = 分子 / 分母
MoM = ( V_t - V_{t-1} ) / V_{t-1} × 100%                 环比变动率
YoY = ( V_t - V_{t-12} ) / V_{t-12} × 100%               同比变动率
Max_flag = ( V_t == MAX( V_{t-11..t} ) )                 历史极值自动标注
```

**变量定义与取值约定：** `Numerator` 与 `Denominator` 分别对应指标的分子与分母工程物理量；`V_{t-1}` 为上月同期值，`V_{t-12}` 为去年同月值；任一基准值为 0 时对应变动率显示 `--`。

#### 【6】展示、对标与判定口径

- 趋势图数值轴起点固定为 0，禁止截断纵轴放大波动。

- 导出字段顺序固定为：组织、统计周期、分子、分母、指标值、环比、同比、数据来源、采集时间戳。

#### 【7】边界条件、异常处理与防错规则
