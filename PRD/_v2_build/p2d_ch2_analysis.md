## 三、能耗能效分析

### 1. 用能结构分析

#### 【1】定位与架构角色

- **功能定位**：全集团能源消费介质结构占比与历史推移结构分析，支撑"以电代气、以绿代灰"的能源清洁化替代决策。
- **承载角色**：P2 园区能碳专员、能耗分析专家。
- **页面路由**：`/monitor/analysis/structure`。
- **上游依赖**：用能在线监测介质消耗数据、折标系数版本库、组织架构四级维度。
- **下游输出**：能源替代方案依据、零碳工厂自评估能源利用维度数据。

#### 【2】业务场景与用户故事

- **业务场景**：全集团各园区在电力、天然气、工业蒸汽、柴油等不同能源介质上的当量消费占比与推移结构分析。
- **用户故事**：
  - As a **能耗分析专家**，
  - I want **穿透分析各生产基地的能源消费结构占比与历史月度推移**，
  - So that **我能制定以电代气、以绿代灰的能源清洁化替代方案**。

#### 【3】功能规格与交互契约

- **全域能源消费圆环图**：展示电力、蒸汽、天然气等按折标煤当量的占比分布。
- **月度用能结构推移堆叠柱状图**：按月份展示各介质消费推移，鼠标悬停展示各分项 tce。
- **车间能耗横向对比柱状图**：客观呈现各生产车间综合能耗排序。
- **维度选择器**：组织（集团 / 产业 / 二级公司 / 车间）+ 时间（月 / 年 / 区间）；上级变更逐级重置下级到首项。
- **口径切换**：支持"当量值 / 等价值"折标口径切换，切换后全页图表同步重算并标注当前口径。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 计算模型/来源 |
|:---|:---|:---|:---|:---|
| 1 | 介质实物消费量 | Decimal | kWh / m³ / t | 用能在线监测按介质汇总 |
| 2 | 折标准煤当量值 | Decimal | tce | 实物量 × GB/T 2589 当量折标系数 |
| 3 | 折标准煤等价值 | Decimal | tce | 实物量 × GB/T 2589 等价折标系数 |
| 4 | 介质折标占比 | Decimal | % | 该介质折标量 / 折标总量 × 100% |
| 5 | 结构推移量 | Decimal | tce | 按月份分组的各介质折标量 |
| 6 | 车间综合能耗排序 | Integer | 名次 | 按折标总量降序，同值并列 |
| 7 | 折标口径标识 | Enum | — | 当量值 / 等价值 |

#### 【5】核心数学模型与算法框架

```math
E_tce_j = Q_j × k_j                                     介质折标煤量（当量或等价口径）
R_j = E_tce_j / Σ ( E_tce_n ) × 100%                    介质折标占比
E_shift_m = Σ_j ( E_tce_j,m )                           第 m 月结构推移总量
Rank_ws = RANK_DESC( E_tce_ws )                         车间能耗排名（降序）
```

**变量定义与取值约定：** `k_j` 为该介质折标系数（当量值 / 等价值两套，取自折标系数管理模块当前生效版本）；占比之和须配平至 100.0%。

#### 【6】展示、对标与判定口径

- **占比口径**：圆环图与堆叠图占比之和强制配平至 100.0%，浮动超过 ±0.1% 触发自检提示。
- **口径一致性**：同一页面内所有图表必须使用同一折标口径，禁止混用当量值与等价值。
- **排序口径**：车间能耗横向对比仅展示客观排序，不标注"先进""落后"等定性标签。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 折标口径标识缺失：页面禁止渲染，强制先选定口径。
> - 某介质无消耗数据：该切片置为 0 并保留图例，不隐藏图例以免误导结构占比。
> - 折标系数版本过期：触发 `E_VAL_FACTOR_EXPIRED`，图表顶部标注"系数待升级"。
> - 除零兜底：折标总量为 0 时全部占比显示 `--`。

```gherkin
    When 系统渲染全域能源消费圆环图
    Then 各介质折标占比之和等于 100.0%
    And 偏差超过 ±0.1% 时触发配平自检提示

  Scenario: 折标口径切换全页联动
    Given 页面当前折标口径为"当量值"
    When 用户切换口径为"等价值"
    Then 圆环图、推移堆叠图与车间对比图同步重算
    And 页面统一标注当前口径为"等价值"
    And 同一页面内不同图表不出现口径混用
```

### 2. 能源成本分析

#### 【1】定位与架构角色

- **功能定位**：电度电费、基本电费、力调电费、天然气费、蒸汽采购费的构成分析与移峰填谷效益模拟，支撑用能成本压降。
- **承载角色**：P2 园区能碳专员、园区财务兼能碳核算专员。
- **页面路由**：`/monitor/analysis/cost`。
- **上游依赖**：能源价格管理分时电价版本、用能在线监测分时电量、基本电费计费方式配置。
- **下游输出**：成本报表、移峰填谷调度建议、储能充放策略依据。

#### 【2】业务场景与用户故事

- **业务场景**：分析电度电费、基本电费、力调电费、天然气费、蒸汽采购费支出，评估分时峰谷价差套利成效与移峰填谷节约潜力。
- **用户故事**：
  - As a **园区财务兼能碳核算专员**，
  - I want **测算各生产车间分时尖峰平谷电费支出与力调电费奖惩**，
  - So that **优化生产排班与储能充放策略，压降综合用能成本**。

#### 【3】功能规格与交互契约

- **成本总览卡片**：综合能源总费用 (万元)、度电平均成本 (元/kWh)、尖峰电费占比 (%)
- **分时费用对比柱状图**：直观展示尖、峰、平、谷各时段费用。
- **移峰填谷效益模拟器**：用户输入预计转移负荷比例，系统自动测算年化电费节约额。
- **力调电费预警**：功率因数低于考核值 0.90 时预警提示。
- **单价版本提示**：页面右上角常驻显示当前生效的能源价格版本与生效日期。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 计算模型/来源 |
|:---|:---|:---|:---|:---|
| 1 | 尖峰时段电费 | Decimal | 元 | $Q_尖 × P_尖$（高电价时段） |
| 2 | 高峰时段电费 | Decimal | 元 | $Q_峰 × P_峰$ |
| 3 | 平时段电费 | Decimal | 元 | $Q_平 × P_平$ |
| 4 | 低谷时段电费 | Decimal | 元 | $Q_谷 × P_谷$（低电价谷段） |
| 5 | 基本电费 | Decimal | 元 | 按变压器容量（元/kVA·月）或最大需量（元/kW·月） |
| 6 | 功率因数调整电费 | Decimal | 元 | 依据国家电力力率调整系数表计算奖惩金额 |
| 7 | 总用电成本 | Decimal | 万元 | $Σ 分时电费 + 基本电费 ± 力调电费$ |
| 8 | 综合度电综合单价 | Decimal | 元/kWh | 总用能费用 / 总用能实物量 |
| 9 | 非电介质成本 | Decimal | 万元 | 各介质用量 × 现行生效单价 |
| 10 | 移峰填谷年化节约额 | Decimal | 万元 | 模拟器按转移比例测算 |

#### 【5】核心数学模型与算法框架

```math
Cost_tou = Σ ( Q_seg × P_seg )                          分时电度电费
Cost_basic = C_capacity × P_cap   或  MD × P_md          基本电费（容量法制或需量法制）
Cost_total = Cost_tou + Cost_basic ± Cost_pf + Σ Cost_media
Cost_pf = f( cosφ ) × Cost_tou                          功率因数调整电费（奖惩）
Unit_price = Cost_total / Σ Q_media                     综合度电综合单价
Save_annual = Q_shift × ( P_peak - P_valley ) × 12       移峰填谷年化节约额
```

**变量定义与取值约定：** `Q_seg` 与 `P_seg` 分别为各时段电量与对应电价；`C_capacity` 为变压器容量；`MD` 为最大需量；`Cost_pf` 依据国家电力力率调整系数表，功率因数 0.90 为不奖不罚考核点；`Q_shift` 为模拟转移负荷量。

#### 【6】展示、对标与判定口径

- **单价口径**：所有单价取自能源价格管理模块**最新生效版本**，跨期价差调整【待补充】。
- **基本电费口径**：计费方式（按容量 or 按最大需量）由配置决定，模拟器须沿用同一口径。
- **力调口径**：功率因数考核基准为 0.90；高于 0.90 为奖励（负值费用），低于为罚金。
- **口径留痕**：费用测算结果可下钻查看所用电价版本与时段划分。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 电价为 0 或未配置：禁止测算，页面提示"待配置当期能源价格"，不输出 0 元结果。
> - 分时电量与总电量不匹配：按总电量为准，分时按比例归一并标注"分时数据待核对"。
> - 除零兜底：总用能实物量为 0 时综合度电单价显示 `--`。
> - 模拟器输入非法：转移比例超出 0~100% 时输入框即时拦截并阻断测算。

#### 【8】QA 自动化验收准则（Gherkin BDD）

```gherkin

  Scenario: 电费构成完整核算

    When 系统核算当月能源成本
    Then 总用电成本 = 尖峰电费 + 高峰电费 + 平时段电费 + 低谷电费 + 基本电费 ± 功率因数调整电费
    And 综合度电综合单价 = 总用能费用 / 总用能实物量

  Scenario: 移峰填谷模拟器输入校验

    Then 输入框即时拦截并阻断测算

  Scenario: 力调电费预警
```

### 3. 单位产品能耗

#### 【1】定位与架构角色

- **功能定位**：变压器、电线电缆两大核心制造主业的单位产品综合能耗与单位电耗核算与权威基准对标。
- **承载角色**：制造车间主任、P2 园区能碳专员。
- **页面路由**：`/monitor/analysis/unit-product`。
- **上游依赖**：ERP 物料主数据、MES 报工质检入库数据、车间能源分摊台账、基准管理国家准入先进值。
- **下游输出**：单耗报表、对标管理排名、零碳工厂自评估产品生态维度数据。

#### 【2】业务场景与用户故事

- **业务场景**：变压器、电线电缆两大核心制造主业的单位产品综合能耗与单位电耗核算与权威基准对标。
- **用户故事**：
  - As a **制造车间主任**，
  - I want **依据本车间变压器额定容量（万 kVA）或线缆长度（km）核算单台产品单耗，与行业先进基准对比**，
  - So that **我能掌握生产工艺能效水平，推进技改升级**。

#### 【3】功能规格与交互契约

**核心硬红线 1：分产业单耗物理量绝对隔离模型**

- 变压器产业（沈变、衡变、新变）：分母统一采用额定容量 `万kVA`（超特高压可折为 MVA），核算指标为**单位产品综合能耗 (tce/万kVA)**、**单位产品电耗 (kWh/万kVA)**、**单位产品蒸汽消耗 (t/万kVA)**。
- 电线电缆产业（鲁缆、新缆、德缆）：分母统一采用产品长度 `km`（或截面标称 `万km·mm²`），核算指标为**单位产品综合能耗 (tce/km)**、**单位产品电耗 (kWh/km)**。
- **隔离铁律**：两类产业单耗在数据库结构、底层 API 响应、页面表格及导出文件中绝对禁止混编在同一统计列中，禁止跨产业直接对比。

**核心硬红线 2：除零安全防御机制**：当统计周期内产量 = 0 时，前端与后端单耗统一安全兜底显示为 `--`，严禁抛出 `NaN`、`Infinity` 或空指针异常。

**核心硬红线 3：10 家无工序单位精准判空**：当切换至沈变智慧能源、印能公司、衡变南京电研、衡变上开、衡变柯贝尔、新变智慧能源、新变银利电气、鲁缆智缆、鲁缆昭和、鲁缆曙光等 10 家无工序直属单位时，单耗工序业务区整行单行干练输出：`暂无相关工序！`

**展示与交互规则：**

- **维度选择**：组织（集团 / 产业 / 二级公司 / 车间）+ 产品型号 + 统计周期。
- **展示内容**：单位产品综合能耗趋势曲线、同比/环比变动率、与准入基准偏差。
- **纵向对比原则**：各基地与车间仅与自身历史对比，严禁跨产业/跨厂横向拉踩。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 计算规则与防错逻辑 |
|:---|:---|:---|:---|:---|
| 1 | 产品型号编码 | String | — | ERP 物料主数据唯一编码 |
| 2 | 所属产业分类 | Enum | 变压器/线缆 | 严格决定分母物理量量纲 |
| 3 | 当期合格品产量 | Decimal | kVA 或 km·mm² | MES 报工质检入库总量，若为 0 单耗置 `--` |
| 4 | 当期消耗总标煤量 | Decimal | tce | 车间各能源介质按工序分摊折标煤累加 |
| 5 | 单位产品综合能耗 | Decimal | tce/kVA 或 tce/km·mm² | $period\_energy\_tce / period\_output$ |
| 6 | 同比变动率 | Decimal | % | (本期单耗 − 去年同期) / 去年同期 × 100% |
| 7 | 环比变动率 | Decimal | % | (本期单耗 − 上月单耗) / 上月单耗 × 100% |
| 8 | 与准入基准偏差 | Decimal | tce/单位 | 本期单耗 − 国家准入先进值 |

#### 【5】核心数学模型与算法框架

```math
e_unit = E_period / M_period                        单位产品综合能耗
q_unit = Q_period / M_period                        单位产品电耗
MoM = ( e_t - e_{t-1} ) / e_{t-1} × 100%            环比变动率
YoY = ( e_t - e_{t-12} ) / e_{t-12} × 100%          同比变动率
Gap = e_unit - Benchmark_admission                  与准入基准偏差
Guard: M_period = 0 → display "--"                  除零安全兜底
```

**变量定义与取值约定：** `E_period` 为统计周期内该产品分摊的折标煤总量（tce）；`M_period` 为当期合格品产量（变压器：kVA 或万 kVA；线缆：km 或 km·mm²）；`Benchmark_admission` 为国家准入先进值。

#### 【6】展示、对标与判定口径

- **分母口径**：分母量纲由产业分类严格决定，变压器为 kVA 系，线缆为 km·mm² 系。
- **对比口径**：各基地与车间仅与自身历史对比，不跨产业、不跨厂横向拉踩。
- **基准口径**：叠加国家限额先进值与准入值参考线；距基准偏差以数值呈现。
- **状态判定**：按标杆值/基准值三色判定，点击指标进入二级详情。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 月度产量为 0：单耗显示 `--`，触发 `E_CALC_UNIT_DIV_ZERO_SOFT`；严禁 NaN 或白屏。
> - 产量录入负数：触发 `E_VAL_PROD_QTY_NEGATIVE`，前端红框拦截阻断提交。
> - 无工序单位：触发 `E_QM_WHITE_LIST_MISS`，整行输出"暂无相关工序！"。
> - 跨产业混算：数据库与 API 层面通过量纲字段强约束，禁止跨产业同列。
> - 锁账拦截：已关账月度的产量数据禁止修改，触发 `E_SYS_ENTRY_ALREADY_LOCKED`。

```math
g = E / G                                           万元产值综合能耗

Gap_adv = g - Limit_advanced                        与先进值偏差

Decline_rate = ( g_current - g_base ) / g_base × 100%   万元产值综合能耗下降率
```

**变量定义与取值约定：** `G` 为当期工业总产值（万元）；`G_nva` 为工业增加值（万元）；`Limit_advanced` 与 `Limit_admission` 为国家限额先进值与准入值，取自基准管理模块；`g_base` 为基准年取值。

**计算口径（`lib/benchmark.ts` 实现，供研发核对）：**

- **达标系数 achievement**：越低越好 = 标杆/实测；越高越好 = 实测/标杆；≥1 即达到或优于标杆。
- **距标杆差距 gapPct**：越低越好 = (实测−标杆)/标杆×100%；越高越好 = (标杆−实测)/标杆×100%。
- **单指标状态**：达标系数 ≥1.00 优秀；0.85~1.00 正常；<0.85 异常。
- **零碳综合得分（0~100）**：对 5 项指标各取 $min(1.15, 达标系数)$ 后求平均，再 ×86，夹逼到 [45, 99]。
- **综合得分三色阈值**：≥90 优秀（绿）；78~89 正常（黄）；<78 异常（红）。

**页面区块与联动：**

- **总览 5 卡**：恒定展示全部 5 项指标（不随所选指标变化），每卡含状态徽章、超大数值、标杆值、"已达标 / 差 N%"与达标度进度条（标杆刻度竖线固定 83.3% 处）。
- **宏观概要 4 卡**：平均零碳得分、达到零碳标杆（达标 = 综合得分 ≥90）实体数/总数、标杆对象（得分最高实体）、管理抓手（得分最低实体 + 其 gapPct 最大的指标，直接点名"抓什么"）。
- **对标红黑榜**：横向条形排名，score 降序、越低越好升序、越高越好降序；前 3 名序号徽章金/银/铜，其余中性灰；条形比例尺 = $min(100, achievement/1.2×100)%$，标杆竖线固定 1/1.2 处。

**子模块划分**：`5.1 核心指标对比`、`5.2 产品单耗对比（横向）`、`5.3 产品单耗对比（纵向）`、`5.4 关键工序单耗对比`、`5.5 基准管理`。

#### 【5】核心数学模型与算法框架

```math
Ach = 越低越好 ? ( Benchmark / Actual ) : ( Actual / Benchmark )
gapPct = 越低越好 ? ( (Actual - Benchmark)/Benchmark×100% ) : ( (Benchmark - Actual)/Benchmark×100% )
Status_item = Ach >= 1.00 ? 优秀 : ( Ach >= 0.85 ? 正常 : 异常 )
Score_total = CLAMP( AVG_i ( MIN(1.15, Ach_i) ) × 86, 45, 99 )
Status_total = Score_total >= 90 ? 优秀 : ( Score_total >= 78 ? 正常 : 异常 )
Bar_ratio = MIN( 100, Ach / 1.2 × 100% )
```

**变量定义与取值约定：** 5 项关键指标分别为单位产品综合能耗、单位产值能耗、单位产品碳排放、绿电占比、单位产品碳足迹；`min` 上限 1.15 用于限制单项过度领先；`×86` 为得分放大系数；夹逼区间 [45, 99] 保证得分可视性。

- **高亮口径**：每行 gapPct 最大的指标单元格红底高亮，作为该行的管理抓手。

| 7 | 主要用能设备能效等级 | Enum | 1级/2级/3级/达标 | 依据能效国标判定 |

#### 【5】核心数学模型与算法框架

```math
E_purchase = E_convert + E_transmit_loss + E_end_use ± Deviation
Deviation_rate = ( E_purchase - E_convert - E_transmit_loss - E_end_use ) / E_purchase × 100%
Loss_ratio = E_transmit_loss / E_purchase × 100%
η_trans = E_out / E_in × 100%                        转换设备效率
Check: | Deviation_rate | > 2% → 标注"平衡偏差待核查"
```

**变量定义与取值约定：** 各环节能耗量均以折标准煤量（tce）为统一量纲；`η_trans` 为锅炉、空压机等转换设备综合效率；平衡偏差率阈值 ±2% 为固定业务铁律。

#### 【6】展示、对标与判定口径

- **量纲口径**：平衡表内部统一折算为 tce，实物量作为辅助列呈现。
- **损耗口径**：输配损耗仅统计计量点之间的差额，不包含未计量区域的估算量。
- **能效等级口径**：主要用能设备能效等级依据现行能效国家标准判定，节能装备应用占比的分子口径与之保持一致。
- **偏差口径**：偏差率绝对值 ≤2% 判定平衡，2%~5% 标注待核查，>5% 强制进入核查流程。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 平衡偏差率超 ±2%：页面自动标注"平衡偏差待核查"并列出偏差最大介质，不抛出技术错误。
> - 某计量点缺失：平衡表该单元格留空并整体标注数据不全，不以 0 代替。
> - 除零兜底：购入侧能耗量为 0 时偏差率与损耗占比显示 `--`。
> - 自评估结论区为空：禁止提交内审，强制填写改进建议清单。
