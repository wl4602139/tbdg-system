# 第二章 零碳园区集控中心功能需求规格

本章严格对应系统切换至【零碳园区集控中心】时的 6 大一级主导航逐层展开，全面覆盖集中监控大屏、集中监管、能耗能效分析、零碳项目评估、统计报表与基础管理六大板块。全章功能权限矩阵见附录 E，验收用例见第十一章，错误码见第五章"标准化错误码字典"。

## 一、集控中心大屏

### 1. 全景环幕大屏 46:9

#### 【1】定位与架构角色

- **功能定位**：集团级对外示范与战略汇报窗口，以 46:9 超宽环幕形态宏观通览全集团园区能源大盘、实时功率流、微电网出力与降碳成效。
- **承载角色**：P1 集团决策层（主视角）；面向省部级领导、全球大客户参观场景。
- **页面路由**：`/monitor/screen/panoramic`；适配 46:9 超宽拼接环幕，支持 4K/8K 分辨率自适应缩放。
- **上游依赖**：IoT 采集网关遥测流、指标管控核算结果、微电网监测数据、组织架构主数据。
- **下游输出**：对外演示态数据快照；全屏轮播切换指令。

#### 【2】业务场景与用户故事

- **业务场景**：面向集团董事长、省部级领导及全球大客户参观特变电工指挥大厅时，宏观通览全集团 15 大园区及 21 家实体工厂的能源大盘、实时功率流、微电网出力与降碳成效。
- **用户故事**：
  - As a **集团高层决策者 (Persona P1)**，
  - I want **在集控中心环幕大屏上一屏穿透全集团实时能耗折标总量、万元产值能耗变动、微电网光储充实时出力与全国制造基地空间分布**，
  - So that **我能掌握集团能碳战略执行进度，对外彰显特变电工世界级绿色智造硬实力**。

**三栏式布局流：**

**关键交互规则：**

- **左侧大盘**：集团综合折标能耗总看板展示当前年度/月度累计能耗（形如 `48,290 tce`）与同比降幅；万元产值综合单耗卡片展示 `0.0526 tce/万元`（同比 `-3.8%`）；8 大能源介质消费占比圆环图外圈呈现电力 (68.4%)、蒸汽 (14.2%)、天然气 (11.1%)、水资源 (3.2%)、柴油/液氮 (3.1%)，悬停展示标煤换算量；24 小时全集团用电负荷走势图展示当日与昨日对比曲线，游标采用微透科技蓝。
- **中央地图**：严格基于国家自然资源部标准地图服务系统官方底图构建，包含十段线、南海诸岛、钓鱼岛及其附属岛屿，右下角永久固化审图号文本（**自然资源部地图审图号合规红线**）；不同产业类型航标展示专属粒子光效（变压器为科技蓝脉冲，线缆为天青蓝脉冲，微电网为翡翠绿脉冲）；点击基地航标滑出轻量浮窗，展示基地瞬时有功负荷、当日光伏发电量、储能充放状态；5 家主力制造工厂（沈变、衡变、新变、鲁缆、德缆）切片胶囊 Tab 支持手动轮播或 30 秒自动巡检切换。
- **右侧微网**：微电网实时出力矩阵展示分布式光伏实时瞬时功率 (MW) 与当日发电量 (MWh)、储能电站当前 SOC 荷电状态 (%) 与充放电状态、柴油发电机应急热备用状态；重点工序能效对标看板展示变压器干燥工序、线缆交联挤出等标杆工序综合能效；实时运行事件流展示近 24 小时设备越限、通讯状态等动态流水。
- **数据状态指示**：试运行演示阶段右上角展示演示标识；生产网联通后自动切换为 `LIVE · 实时生产`。
- **客观中立原则**：大屏全量图表与卡片严禁出现"表现优异""落后单位"等定性评语，统一以客观数值与客观时序环比（如 `同比 -2.4% ↓`）自解释。

#### 【5】核心数学模型与算法框架

```math
E_group = Σ ( E_park_i )               集团累计综合能耗 = 各园区折算能耗求和
E_park_i = Σ ( Q_ij × k_j )            第 i 园区能耗 = 各介质实物量 × 折标准煤系数
R_media_j = Q_j · k_j / Σ ( Q_n · k_n )  第 j 种介质折标占比
Δ_E_yoy = ( E_current - E_last_year ) / E_last_year × 100%   同比变动率
```

**变量定义与取值约定：** `Q_ij` 为第 i 园区第 j 种能源介质实物消耗量；`k_j` 为第 j 种介质折标准煤系数（引用 GB/T 2589-2020 当量值）；`R_media_j` 为第 j 种介质折标煤消费占比；`Δ_E_yoy` 低于 0 表示同比下降（节能成效），显示为绿色。

#### 【6】展示、对标与判定口径

- **对比口径**：全部同比/环比以箭头 + 三色表达（绿：下降；红：上涨；灰：持平），遵循国内工业能耗语义。
- **介质占比口径**：占比以折标准煤当量为统一量纲，严禁以实物量直接对比。
- **航标聚合口径**：产业集团节点展示下级园区加总；园区节点展示本园区实测值，禁止跨层级混算。
- **轮播节奏**：自动巡检周期固定 30 秒，手动操作后暂停 60 秒再恢复。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - **地图合规红线**：底图与审图号不可动态替换、不可缩放至裁剪十段线；违规判定为阻断级缺陷。
> - **越权红线**：大屏默认只读，禁止在大屏路由内提供任何数据写入口。
> - 遥测心跳超 5 秒未响应：触发 `E_IO_MQTT_TIMEOUT`，图表展示最近一次缓存读数并打"数据延迟"微标签。
> - 边缘一体机物理断网：触发 `E_IO_GATEWAY_OFFLINE`，启动本地断点续传，恢复联网后自动同步。
> - 主库连接断开：触发 `E_SYS_DB_CONN_LOST`，30 秒内备库接管并切换只读模式。
> - 分母产值为 0：单耗显示 `--`，严禁 NaN 或白屏。

### 2. 综合集控大屏 16:9

#### 【1】定位与架构角色

- **功能定位**：面向园区中控室 7×24 小时连续运行监视的标准 16:9 大屏，聚焦全域尖峰平谷用电结构、储能充放循环与能效平衡。
- **承载角色**：P2 园区能碳专员（运行班长、能效运营工程师）。
- **页面路由**：`/monitor/screen/integrated`；适配 1920×1080 / 2560×1440 / 3840×2160。
- **上游依赖**：分时电能遥测、能效对标核算结果、微电网监测数据。
- **下游输出**：削峰填谷调度指令依据、越限事件推送告警中枢。

#### 【2】业务场景与用户故事

- **业务场景**：园区中控室运行班长与能效专员进行 7×24 小时连续运行监视，跟踪全域尖峰平谷用电结构、基地储能充放循环与能效平衡。
- **用户故事**：
  - As a **园区能效运营工程师 (Persona P2)**，
  - I want **在标准 16:9 集控大屏上实时监控全集团各经营单位当月用电峰平谷配比与基准线偏差**，
  - So that **我能精准调度微电网削峰填谷，降低全厂尖峰电费支出**。

#### 【3】功能规格与交互契约

#### 【5】核心数学模型与算法框架

```math
Q_total = Q_tip + Q_peak + Q_flat + Q_valley            当日累计电量 = 四时段用电量之和
R_valley = Q_valley / Q_total × 100%                    谷段电量占比（越高越好）
Gap = KPI_actual - KPI_national_advanced                能效对标偏差量
E_saved = T_shift × ( P_peak - P_valley ) × η_storage   移峰填谷理论节约金额
C_reduce = P_pv_self × EF_grid                          绿电自发自用减排量
N_tree = C_reduce / 18.3                                等效植树量（1 棵树年均固碳 18.3 kgCO2）
```

**变量定义与取值约定：** `Q_tip/peak/flat/valley` 分别对应尖、峰、平、谷时段电量；`T_shift` 为转移负荷时长；`P_peak/P_valley` 为峰谷电价；`η_storage` 为储能充放综合效率（默认 0.88）；`P_pv_self` 为光伏自发自用量；`EF_grid` 为区域电网排放因子。

#### 【6】展示、对标与判定口径

- **时段口径**：尖/峰/平/谷时段划分严格取自能源价格管理模块最新生效版本，跨版本切换时页面提示时段变更。
- **对标口径**：仅与项目公司同层级实体横向对比，项目公司/在建单位不参与排名与达标统计。
- **等效换算口径**：等效植树按 1 棵成年乔木年均固碳 18.3 kgCO2 折算；等效节约标煤按 GB/T 2589 当量值折算。
- **刷新周期**：分时负荷与微网数据 15 分钟刷新，时钟与通讯状态 1 秒刷新。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 分时四段电量之和与累计电量偏差超过 0.5%：页面标注"分时数据待核对"，不在大屏上抛出技术错误码。
> - ETS/电价外链数据源不可用：按最近有效版本测算并标注价格时间戳。
> - 光伏与储能设备全部离线：象限 C 输出单行客观结论"当前无光伏/储能数据"，严禁空白占位卡片。
> - 除零兜底：谷段占比、消纳比等分母为 0 时统一显示 `--`。
