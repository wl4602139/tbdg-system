# 第三章 产品碳足迹集采中心功能需求规格

本章严格对应系统切换至【产品碳足迹集采中心】时的 6 大一级主导航逐层展开，全面支撑产品全生命周期 LCA 建模、ISO 14067 认证、二维码数字碳标签与欧盟 CBAM 关税申报。本章功能权限矩阵见附录 E（P4 LCA 工程师 / P5 报关专家 / P6 外部审计机构），北极星指标（NSM）见附录 F，验收用例见第十一章 Gherkin 准则；LCA / CBAM 错误码见第五章"标准化错误码字典"。

## 一、对外示范窗口

### 1. 碳足迹总览驾驶舱

#### 【1】定位与架构角色

- **功能定位**：面向国际客户、海外驻华使节及欧盟碳关税审查专员的高端碳驾驶舱，全屏呈现主力出口产品 LCA 碳足迹全景桑基图、防伪二维码数字碳标签、绿电消纳减碳成果与 CBAM 关税节省测算总览。
- **承载角色**：P4 碳核算工程师（运维）、P5 报关与关税专家（讲解）、P6 外部独立审计机构（核验）。
- **页面路由**：`/carbon-footprint/demo`。
- **上游依赖**：LCA 核算引擎结果、数字碳标签、绿电消纳数据、CBAM 关税模拟结果。
- **下游输出**：对外脱敏展示快照、二维码查验演示入口。

#### 【2】业务场景与用户故事

- **业务场景**：国际客户验厂与欧盟合规审查场景，需以可视化方式证明产品碳足迹的核算边界、数据来源与第三方认证有效性。
- **用户故事**：
  - As a **碳核算与认证工程师 (Persona P4)**，
  - I want **在对外示范驾驶舱全屏展示产品 LCA 五阶段碳排构成、可扫码验证的数字碳标签与 CBAM 关税节省测算**，
  - So that **我能以权威可视化证据赢得国际客户与欧盟审查专员的信任**。

#### 【3】功能规格与交互契约

**核心展示要素：**

- **LCA 碳足迹全景桑基图**：以五阶段（原材料获取 / 上游运输 / 制造加工 / 试验检测 / 包装出厂）流向呈现单台产品碳足迹构成。
- **防伪二维码数字碳标签**：展示 EPC 编码与防伪签名哈希，支持现场扫码弹窗查验。
- **绿电消纳减碳量化成果**：展示光伏自发自用减排量与等效植树量。
- **CBAM 关税节省测算总览**：展示累计关税节省金额与国内碳成本抵扣情况。

**交互与刷新规则：**

- **全屏轮播**：面向参观与验收场景默认全屏自动轮播，关键指标卡循环展示，支持手动切换与暂停（轮播周期【待确认】）。
- **据点下钻**：点击桑基图节点或标签卡，下钻至实景数据库对应物料/产品明细。
- **二维码查验演示**：扫码弹窗呈现 EPC 编码、防伪签名哈希与溯源链摘要（详见三、3 数字碳标签）。
- **刷新策略**：LCA 指标按日结刷新，欧盟碳价按小时级联动刷新（【待确认】）。
- **【待补充】** 对外展示数据脱敏规则与白名单（面向外部参观者的字段裁剪）。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 数据来源与核算逻辑 |
|:---|:---|:---|:---|:---|
| 1 | 单台产品全生命周期碳排 | Decimal | kgCO2e/台 或 kgCO2e/km | LCA 5 大阶段排放滚算累加 |
| 2 | 原材料获取阶段碳排占比 | Decimal | % | $(E_{原材料} / E_{总碳足迹}) × 100%$ |
| 3 | 制造加工阶段碳排占比 | Decimal | % | $(E_{加工} / E_{总碳足迹}) × 100%$ |
| 4 | 绿电消纳贡献减排量 | Decimal | kgCO2e | 光伏自发自用量 × 区域电网碳因子 |
| 5 | CBAM 关税累计节省金额 | Decimal | €（欧元） | 已抵扣国内碳成本折算节省关税 |
| 6 | 防伪数字验真哈希 | String | SHA-256 | 产品批次 + 认证机构私钥数字签名 |
| 7 | 产品 EPC 编码 | String | — | 全球产品电子代码，唯一 |
| 8 | 认证机构名称 | String | — | SGS / TÜV 南德 / 中国方圆 |

#### 【5】核心数学模型与算法框架

```math
E_PCF = E_raw + E_trans + E_manuf + E_test + E_pack      单台产品全生命周期碳足迹
R_stage = E_stage / E_PCF × 100%                          各阶段碳排占比
Save_CBAM = Export_Qty × Embedded_Carbon × ( Price_EU_ETS - Price_Domestic )
Hash_sign = SIGN_SHA256( BatchNo + PrivateKey_CA )        防伪签名哈希
```

**变量定义与取值约定：** 五阶段碳排定义详见本章三、2 LCA 核算引擎；`Price_EU_ETS` 为欧洲能源交易所碳配额结算均价；`Price_Domestic` 为国内已支付碳成本折算价。

#### 【6】展示、对标与判定口径

- **边界口径**：对外展示统一采用 Cradle-to-Gate（摇篮到大门）边界，并在页面明确标注。
- **数据脱敏口径**：对外展示版本按白名单裁剪字段，不呈现供应商名称、工艺配方等 L2 以上敏感信息。
- **时效口径**：页面底部常驻展示数据截止时间与因子版本号。
- **口径一致性**：对外展示的碳足迹数值必须与已签发认证报告完全一致，不允许展示草稿态数据。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 仅可展示状态为"已认证 / 已发布"的 LCA 报告数据，草稿与送审态数据一律不上屏。
> - 对外展示不得包含未脱敏的供应商名称、工艺配方等敏感字段。
> - 欧盟碳价超 24 小时未同步：触发 `E_EXT_ETS_PRICE_STALE`，页面标黄并标注价格时间戳。
> - 二维码签名校验失败：弹窗标注"验真失败"并不展示溯源明细。
> - 无已签发报告的产品：入口不出现，不显示空白占位。

#### 【8】QA 自动化验收准则（Gherkin BDD）

```gherkin

    When 对外示范驾驶舱渲染 LCA 碳足迹全景桑基图
    Then 仅呈现状态为"已认证"或"已发布"的报告数据
    And 草稿态与送审态数据不入屏

  Scenario: 二维码验真演示
    Given 某产品数字碳标签已由认证机构签发
    When 参观者扫码触发查验弹窗
    Then 弹窗呈现 EPC 编码、防伪签名哈希与溯源链摘要
    And 签名校验失败时标注"验真失败"且不展示溯源明细

  Scenario: 碳价滞后的客观提示
    Given 欧洲能源交易所 ETS 价格超过 24 小时未同步

    Then 结果上方以黄色提示框注明碳价滞后并展示价格时间戳
    And 返回 E_EXT_ETS_PRICE_STALE
```

## 二、多维分析

### 1. 横向对比分析

#### 【1】定位与架构角色

- **功能定位**：支持不同生产基地生产的同规格产品按五大阶段横向对标，挖掘各基地工艺工序降碳潜力。
- **承载角色**：P4 碳核算工程师、P2 园区能碳专员。
- **页面路由**：`/carbon-footprint/analysis/compare`。
- **上游依赖**：LCA 核算引擎结果、产品 BOM、经营单位主数据、销售订单与生产计划。
- **下游输出**：基地降碳改进清单、碳热点分析输入。

#### 【2】业务场景与用户故事

- **业务场景**：集团层面比较沈变厂与衡变厂同型号 220kV 油浸式变压器的碳足迹差异，定位工艺工序降碳空间。
- **用户故事**：
  - As a **碳核算与认证工程师 (Persona P4)**，
  - I want **选择同规格产品按五大阶段横向对标各生产基地的单位产品碳足迹并下钻至主材与工序构成**，
  - So that **我能精准定位各基地的工艺降碳潜力并推动横向最佳实践复制**。

#### 【3】功能规格与交互契约

- **业务级联筛选器**：产业 → 产线 → 产品类别 → 产品型号（可搜索 ComboBox）→ 经营单位 → 销售订单 → 生产计划；上级变更逐级重置下级到首项。
- **特征量（feature）**：变压器按 kVA、电缆按 km、开关按 台/间隔，单位产品碳足迹以 kgCO2/特征量 表达，保证跨型号可比。
- **重点指标区**：3 张 KpiCard（对比经营单位数、生产总数、单位产品碳足迹均值）。
- **主对比图**：BarBenchmark 横向对比各经营单位单位产品碳足迹，基准线为虚线，超基准柱标红，达标柱主色。
- **经营单位排名表**：按单位产品碳足迹升序，第 1 名挂 Award 标杆徽标；项目公司行置灰且不计入排名序号；每行右侧"下钻"。
- **下钻弹窗（Modal）**：标题 = 型号 + 经营单位；内容含 ① 生命周期构成 Donut（原材料/生产/运输…）② 主材碳排条形 ③ 工序碳排条形 ④ 该单位该型号销售订单列表（客户/数量/单台 tCO2/拆分生产计划标签）；底部"碳足迹详情"跳转实景数据库 / 碳足迹核算。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 校验与约束规则 |
|:---|:---|:---|:---|:---|
| 1 | 产业分类 | Enum | — | 变压器/线缆/开关，决定特征量口径 |
| 2 | 产品型号 | String | — | ERP/PLM 物料主数据编码，非空 |
| 3 | 经营单位 | String | — | 六级组织架构经营单位节点 |
| 4 | 特征量数值 | Decimal | kVA / km / 台 | > 0，作为单位产品碳足迹分母 |
| 5 | 单位产品碳足迹 | Decimal | kgCO2/特征量 | $E_{PCF} / Feature$，分母为 0 显示 `--` |
| 6 | 单位产品碳足迹均值 | Decimal | kgCO2/特征量 | 所选范围内算术平均，空集显示 `--` |
| 7 | 基准值 | Decimal | kgCO2/特征量 | 取自基准管理配置 |
| 8 | 达标状态 | Enum | — | 达标（主色）/ 超基准（红色） |
| 9 | 销售订单数量 | Decimal | 台 / km | 关联销售订单实际数量 |
| 10 | 项目公司标识 | Boolean | — | 为真时该行置灰且不计入排名 |

#### 【5】核心数学模型与算法框架

```math
CF_unit = E_PCF / Feature                                 单位产品碳足迹
R_stage = E_stage / E_PCF × 100%                          各阶段构成占比
Mean_unit = Σ CF_unit,i / N                               单位产品碳足迹均值
Status = CF_unit <= Benchmark ? 达标 : 超基准              达标判定
```

**变量定义与取值约定：** `Feature` 为特征量（变压器 kVA、电缆 km、开关 台/间隔）；`E_PCF` 为该单位该型号的单台全生命周期碳足迹。

#### 【6】展示、对标与判定口径

- **可比口径**：所有对比必须在同一特征量口径下进行，严禁跨特征量（如 kVA 与 km）直接对比。
- **基准口径**：基准线取自基准管理配置，超基准柱标红。
- **排名口径**：按单位产品碳足迹升序排名，第 1 名为低碳标杆；项目公司行置灰且不计入排名序号。
- **筛级口径**：上级筛选变更时逐级重置下级到首项，避免残留无效组合。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 特征量为 0 或缺失：单位产品碳足迹显示 `--`，该实体不参与排名与均值计算。
> - 筛选组合无数据：主对比图与排名表输出客观空态"当前条件下无可比数据"，不显示空白占位卡片。
> - 跨特征量对比：前端禁止（下拉互斥），后端 API 拒绝混合特征量请求。
> - 项目公司：强制置灰并排除排名统计。

#### 【8】QA 自动化验收准则（Gherkin BDD）

```gherkin
Feature: 碳排横向对比分析
  Scenario: 级联筛选器逐级重置
    Given 用户已在级联筛选器中选定"变压器产业 / 高压产线 / 220kV 油浸式变压器"
    When 用户将产业改为"线缆产业"
    Then 产线、产品类别、产品型号、经营单位等下级筛选器逐级重置到首项
    And 主对比图与排名表同步刷新

  Scenario: 项目公司排除排名
    Given 对比范围中包含项目公司
    When 系统生成经营单位排名表
    Then 项目公司行置灰且不计入排名序号
    And 不参与单位产品碳足迹均值计算

  Scenario: 特征量为零安全兜底
    Given 某经营单位某型号产品的特征量数值缺失
    When 页面渲染该行的单位产品碳足迹
    Then 该值显示为 "--"
    And 该行不参与降序排名与均值统计
```

### 2. 纵向追溯分析

#### 【1】定位与架构角色

- **功能定位**：按批次号追踪同一产品历年碳足迹演变趋势，提供原材料替代、绿电消纳提升及工艺优化的敏感性归因瀑布图。
- **承载角色**：P4 碳核算工程师、技改项目经理。
- **页面路由**：`/carbon-footprint/analysis/ranking`。
- **上游依赖**：批次级 LCA 核算结果、生产计划与销售订单、原材料替换记录。
- **下游输出**：减碳路径建议、技改立项依据。

#### 【2】业务场景与用户故事

- **业务场景**：追踪某主力型号变压器近 3 年碳足迹下降路径，量化高磁感取向硅钢片替代与绿电接入各自的贡献度。
- **用户故事**：
  - As a **碳核算与认证工程师 (Persona P4)**，
  - I want **按批次追踪同型号产品碳足迹演变，并以瀑布图量化各减碳举措的贡献度**，
  - So that **我能识别最有效的减碳路径并复制到其他产线**。

#### 【3】功能规格与交互契约

- **左侧经营单位组织树**：集团 → 板块 → 经营单位，可展开/收起；项目公司置灰；点击切换 scope（默认"全部经营单位" = 跨单位均值）。
- **级联筛选**：产业 / 产线 / 类别 / 时间。
- **重点指标区**：3 张 KpiCard（型号数量、生产总数、单位产品碳足迹均值，随 scope 重算）。
- **红榜 Top5 / 黑榜 Top5**：型号按单位产品碳足迹升序，前 n 入红榜（低碳标杆），后 n 入黑榜（改进对象）；红榜第 1 挂 Award、黑榜第 1 挂 TriangleAlert。
- **点击榜单卡片下钻（Modal）**：各生产计划单台碳足迹对比条形（同型号不同生产计划 = 不同时间生产的横向对比）+ 销售订单及拆分生产计划表。
- **场景定位**：按组织范围对同类别各型号做红黑榜，锁定改进对象。
- **归因瀑布图**：以瀑布图形呈现原材料替代、绿电接入、工艺优化等因素对碳足迹变动的贡献量与贡献率。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 校验与约束规则 |
|:---|:---|:---|:---|:---|
| 1 | 产品型号 | String | — | 唯一主数据编码 |
| 2 | 生产批次流水号 | String | — | MES 制造工单流水号 |
| 3 | 生产计划标识 | String | — | 同一型号下按时间拆分的生产计划 |
| 4 | 单位产品碳足迹 | Decimal | kgCO2e/特征量 | ≥ 0，空值显示 `--` |
| 5 | 碳足迹变动量 | Decimal | kgCO2e/特征量 | 本期 − 基期，可正可负 |
| 6 | 归因贡献率 | Decimal | % | 各因素贡献量 / 总变动量 × 100% |
| 7 | 红榜排名 | Integer | 名次 | 升序取前 5，第 1 名挂标杆徽标 |
| 8 | 黑榜排名 | Integer | 名次 | 升序取后 5，第 1 名挂警示徽标 |
| 9 | 组织范围（scope） | Enum | — | 具体经营单位 / 全部经营单位（跨单位均值） |

#### 【5】核心数学模型与算法框架

```math
ΔCF = CF_t - CF_base                                    碳足迹变动量
Con_i = ΔCF_i / ΔCF × 100%                              各因素归因贡献率
CF_scope_all = Σ CF_unit,i / N                          跨单位均值
Top_red = ORDER_BY( CF_unit ) ASC LIMIT 5               红榜（低碳标杆）
Top_black = ORDER_BY( CF_unit ) DESC LIMIT 5            黑榜（改进对象）
```

**变量定义与取值约定：** `ΔCF_i` 为第 i 项减碳举措（原材料替代、绿电接入、工艺优化）带来的碳足迹变化量；归因贡献率之和应为 100%，偏差超 ±1% 提示归因不完整。

#### 【6】展示、对标与判定口径

- **时间口径**：纵向追溯以生产批次时间轴为准，不以销售订单时间为准。
- **均值口径**：scope 为"全部经营单位"时采用跨单位算术平均，非加权。
- **红黑榜口径**：红黑榜基于同类别内各型号升序排序，前 5 与后 5，型号数少于 10 时不重复上榜。
- **归因口径**：归因须完整覆盖全部减碳举措，贡献率之和强制配平至 100%。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 同型号历史批次少于 2 个：不绘制归因瀑布图，输出客观提示"历史批次不足，暂不支持归因"。
> - 归属贡献率之和不等于 100%：标注"归因待补充"并列出未归因残差。
> - 项目公司：置灰且不参与红黑榜。
> - 除零兜底：总变动量为 0 时贡献率显示 `--`。

#### 【5】核心数学模型与算法框架

```math

CF_process = E_manuf + E_test                         生产环节碳排
Gap_pct = ( CF_unit - Benchmark ) / Benchmark × 100%  与基准偏差率
Status = CF_unit <= Benchmark ? 达标 : ( CF_unit <= 1.05 × Benchmark ? 接近 : 超标 )
```

**变量定义与取值约定：** 偏差率 ≤0% 达标、0~5% 接近、>5% 超标；基准值可由用户修改并即时联动重算判定色。

### 4. 碳热点分析与模拟

#### 【1】定位与架构角色

- **功能定位**：依据生产环节及原材料主材自动生成碳足迹构成图并识别排放热点，支持原材料替换与绿电接入的情景模拟。
- **承载角色**：P4 碳核算工程师、技改项目经理、产品技术部。
- **页面路由**：`/carbon-footprint/analysis/hotspot`。
- **上游依赖**：LCA 核算引擎结果、因子库、原材料替代料对照表。
- **下游输出**：低碳技术选型建议、模拟方案报告附件。

#### 【2】业务场景与用户故事

- **业务场景**：产品研发阶段评估"再生铜替代原生铜"与"绿电接入"两类方案的减排潜力，为低碳设计决策提供量化依据。
- **用户故事**：
  - As a **碳核算与认证工程师 (Persona P4)**，
  - I want **识别碳足迹构成中贡献度最高的热点项，并对原材料替换与绿电接入做情景模拟对比**，
  - So that **我能为低碳技术选型提供量化减排潜力证据**。

#### 【3】功能规格与交互契约

**业务逻辑：**

- 依据生产环节及原材料主材自动生成碳足迹构成饼图/柱状图，识别排放热点（贡献度排序、帕累托分析）。
- **情景模拟**：支持"原材料替换"（如再生铜替代原生铜，单台产品碳足迹减少 Y%）、"绿电接入"等场景的减排潜力模拟，辅助低碳技术选型。
- **模拟结果对比**：基准情景 vs 模拟情景碳足迹差额与减排率，可保存为模拟方案并纳入报告附件。
- **【待补充】** 模拟参数项（替换料因子、绿电比例、工艺节拍）由项目组确认。

**交互规则：**

- 帕累托图自动标注累计贡献率达 80% 的热点项集合（关键少数）。
- 情景模拟采用"基准情景 / 情景 A / 情景 B"三栏对比卡片，差额与减排率以差值徽章呈现。
- 模拟方案保存后生成唯一方案编号，可挂载至 LCA 报告附件。

#### 【4】页面字段字典与数据契约

| 序号 | 字段中文名称 | 数据类型 | 工程单位 | 校验与约束规则 |
|:---|:---|:---|:---|:---|
| 1 | 热点项名称 | String | — | 主材名称或工序名称，非空 |
| 2 | 碳排贡献量 | Decimal | kgCO2e | ≥ 0 |
| 3 | 贡献度占比 | Decimal | % | 各热点项占比之和为 100% |
| 4 | 累计贡献度 | Decimal | % | 用于帕累托分析，标注 80% 分界 |
| 5 | 基准情景碳足迹 | Decimal | kgCO2e/台 | 来自当前 LCA 核算结果 |
| 6 | 模拟情景碳足迹 | Decimal | kgCO2e/台 | 应用替换参数后重算结果 |
| 7 | 减排量 | Decimal | kgCO2e/台 | 基准 − 模拟，≥ 0 为有效减排 |
| 8 | 减排率 | Decimal | % | 减排量 / 基准情景 × 100% |
| 9 | 模拟方案编号 | String | — | 保存后生成，格式 `SIM-<年>-<序号>` |

#### 【5】核心数学模型与算法框架

```math
Con_i = E_item,i / E_PCF × 100%                            单项贡献度占比
Σ Con_i = 100%                                             占比配平约束
Pareto_80 = MIN_SET( |S| ) s.t. Σ_{i∈S} Con_i >= 80%       帕累托关键少数
ΔCF_sim = CF_base - CF_sim                                 模拟减排量
Rate_reduce = ΔCF_sim / CF_base × 100%                     减排率
```

**变量定义与取值约定：** `E_item,i` 为第 i 个热点项的碳排贡献量；替换料因子取自因子库（如再生铜与原生铜因子比）；绿电比例取值范围 0%~100%。

#### 【6】展示、对标与判定口径

- **热点口径**：贡献度按主材与工序两个维度分别排序，同一项不重复计数。
- **帕累托口径**：累计贡献度首次达到 80% 时对应的最小项目集合判定为关键少数。
- **模拟口径**：模拟结果为理论潜力值，须标注"模拟测算值，非实测"，不得直接用于认证报告正文。
- **方案口径**：模拟方案仅作为报告附件与决策依据，不得直接覆盖正式核算结果。

#### 【7】边界条件、异常处理与防错规则

> ⚠️ 【研发设计红线与强约束校验】
> - 模拟参数缺失（替换料因子或绿电比例未配置）：模拟按钮置灰并提示待配置项。
> - 模拟结果必须标注"模拟测算值，非实测"，严禁混入认证报告正文。
> - 替换料因子过期：触发 `E_VAL_FACTOR_EXPIRED`，阻断模拟。
> - 除零兜底：基准情景碳足迹为 0 时减排率显示 `--`。
