## 一、 五大核心业务 Tab 同构规格

工作台统一收敛基层离线填报与设备底账维护，提供 5 个标准 Tab：
1. **产品产量录入 (`production`)**：生产单位、工序、产品名称选择；同类型产品产量数据行跨行合并居中；支持台/kVA/km/吨/件级联单位；
2. **能源消耗录入 (`energy`)**：与产量 100% 同构，支持电/水/气/汽四类介质分类填报，支持按车间与用能单元填报；
3. **园区相册维护 (`album`)**：支持光伏电站、储能厂房实景图片上传，自动压缩至 1920×1080 并生成高保真缩略图；
4. **园区大事记维护 (`milestone`)**：时间轴节点式录入绿色低碳重大事件与技改节点；
5. **节能装备与台账录入 (`equipment`)**【新增】：
   - 录入并维护驱动系统核心指标 **#9 节能装备应用占比** 的两大底层基准功率：**节能装备累计额定总功率 ($R_{es}$)** 与 **纳入统计范围装备累计额定总功率 ($E_{ts}$)**；
   - 维护 **⚡ 节能装备明细表**（高能效等级装备资产明细、认证凭证与投运年份）；
   - 维护 **📋 全厂在册装备底账**（全厂主要用能装备台账、工况、统计范围标记与能效属性）。

## 二、 节能装备与台账数据录入功能规格 (`equipment`)

### 1. 业务场景与指标驱动关系
- **国家工业节能标准要求**：依据国家工信部《重点用能产品设备能效先进水平、节能水平和准入水平》及《国家工业节能监察技术指南》，工厂必须核算达到能效国标 2 级（含）以上或符合节能装备目录的装备在全厂统计装备中的总容量/总功率比重。
- **数学模型与算法契约**：
  $$\text{节能装备应用占比 } S = \frac{R_{es}}{E_{ts}} \times 100\%$$
  - $R_{es}$ (Energy Saving Equipment Power)：节能装备累计额定总功率，单位 $\text{kW}$；
  - $E_{ts}$ (Total In-Scope Equipment Power)：纳入统计范围装备累计额定总功率，单位 $\text{kW}$；
  - 偏差量展示口径：客观中立呈现与设定考核基准（如 $75.0\%$）的客观偏差量 $\Delta = S - 75.0\%$，杜绝“表现优异/落后”等定性评判词汇。

### 2. 页面布局与 Bento 4 列 KPI 录入看板
工作台顶部设立 4 栏响应式 Bento 录入控制面板：
1. **节能装备累计额定总功率 ($R_{es}$)**：
   - 核心输入框（单位：$\text{kW}$，精度 0.1 kW）；
   - 提供辅助功能：【从明细重算】按钮（点击后自动遍历明细表中所有节能装备的额定功率并求和反填）；
   - 统计标记：展示当前明细表中在册节能装备台数（如“基于明细表 8 台设备求和”）。
2. **纳入统计范围装备累计额定总功率 ($E_{ts}$)**：
   - 核心输入框（单位：$\text{kW}$，精度 0.1 kW）；
   - 提供辅助功能：【从台账重算】按钮（点击后自动过滤全厂底账中 `inScope === true` 的装备并求和反填）；
   - 统计标记：展示当前纳入统计装备台数（如“基于台账 13 台在册装备”）。
3. **节能装备应用占比 ($S$) 动态看板**：
   - 动态主数值展示（如 `79.7%`，大号 Mono 等宽加粗字体）；
   - 动态进度条（实心科技蓝，依据百分比自适应填充）；
   - 客观基准偏差标签：客观显示与设定考核基准偏差（例如基准 75.0% 时显示 `+4.7%` 或 `-2.1%`）。
4. **能效结构分布与批量操作面板**：
   - 能效结构徽章：清晰展示国标 1 级超高效、国标 2 级高效及普通装备台数占比；
   - 工具操作组：【下载台账模板】（.xlsx 标准模板）、【批量导入】按钮。

## 三、 两大 44px 工业高密数据明细表格规格

通过内嵌子 Tab 切换器支持两大明细表的独立维护：

### 1. ⚡ 节能装备明细表 (`energy_saving_equipments`)

- **字段契约与 Schema**：
  | 字段英文 Key | 中文字段名称 | 数据类型 | 单位 | 必填 | 业务规则与防错说明 |
  | :--- | :--- | :--- | :--- | :---: | :--- |
  | `id` | 设备主键 ID | String | - | 是 | 唯一编号 (如 `EQ-ES-01`) |
  | `code` | 资产台账编码 | String | - | 是 | ERP/EAM 资产编码 (如 `TBEA-SB-2023-014`) |
  | `name` | 设备名称 | String | - | 是 | 标准装备名称 (如 `变频螺杆式空压机 1#`) |
  | `model` | 规格型号 | String | - | 是 | 设备出厂型号 (如 `Atlas GA-110VSD+`) |
  | `ratedPowerKw` | 额定功率 | Number | kW | 是 | 必须 > 0，**支持行内直接修改并失焦即时重算联动** |
  | `energyGrade` | 能效国标等级 | Enum | - | 是 | `国标1级(超高效)` / `国标2级(高效)` |
  | `workshop` | 所属工序/车间 | String | - | 是 | 对应白名单车间 (如 `动力动力车间`) |

- **操作能力**：支持单行行内功率编辑、编辑模态框完整修改、删除确认、新增装备模态框。

  | `code` | 资产编码 | String | - | 是 | EAM 固定资产账卡号 (如 `TBEA-EAM-00101`) |

## 四、 强制防错校验与数据完整性规范

1. **功率越限告警防错 ($R_{es} \le E_{ts}$)**：
   - 当录入或重算后的节能装备功率 $R_{es}$ 严格大于纳入统计范围总功率 $E_{ts}$ 时，即时触发逻辑异常警示；
   - 界面弹出黄色告警边框与明确提示文案：`⚠️ 逻辑异常：节能装备功率 (XXX kW) 不得大于纳入统计总功率 (XXX kW)，请核查台账！`；
   - 阻断月度数据提交保存。
2. **强制非负校验**：
   - 任何设备功率输入框输入负数时立即触发 `E_VAL_POWER_NEGATIVE`，输入框红色高亮并自动阻断提交。
3. **行内失焦/回车更新 (Blur / Enter Trigger)**：
   - 允许操作人员直接在明细表格中修改额定功率，失焦 (`onBlur`) 或按回车 (`onKeyDown(Enter)`) 时，系统自动重新计算明细表汇总值及全厂总台账，并同步刷新上方 KPI 输入框中的累计功率。
4. **客观中立原则**：
   - 严禁在界面中引入定性评级词汇，所有进度展示均以数值对比与客观时序对比体现。
