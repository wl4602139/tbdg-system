> **受控编号**：`TBEA-PRD-APPENDIX-FIELD-SSOT-2026`

> **密级**：内部绝密 (L4 - Top Secret)

## 一、 需求背景与问题定义 (Problem Statement)

在前期平台页面迭代过程中，因不同页面或功能组件由不同设计和研发批次完成，导致了以下显著的用户体验与业务一致性缺陷：
1. **同义异名问题**：例如在【能效对标分析】中称呼为 `产品中类`，而在系统配置或部分表单中被写为 `产品种类`；
2. **板块标题冗长自述**：例如在【用能在线监测】中，首排用电板块被命名为 `电力负荷与消纳整体监测 (总用电量 = 市电用量 + 消纳绿电量)`，既违背 `tbea-industrial-design` 极简克制准则，又与【指标管控看板】的 `电力数据` 脱节；
3. **时序对标用语杂乱**：存在 `同比增长`、`同比变动`、`碳排同比` 等多种别名；且一度出现受工业排产干扰严重的 `环比` 指标；
4. **设备与工序标题不统一**：例如在【重点用能设备】卡片头部显示具体设备编号而非规范的 `监测设备`；【指标管控看板】第三板块在不同跳转状态下出现 `关键制造工序能耗管控指标`、`关键工序能耗` 等不一致称呼。

为确保系统具备工业互联网级的高严谨性与人机交互一致性，本 PRD 制定《全域统一字段与术语标准规范》，作为全平台需求规格、原型交互设计、前后端 API 契约及测试验收的单源真理 (SSOT)。

## 二、 核心治理原则与架构约束 (Architecture & Governance Rules)

### 1. 唯一单源真理 (SSOT) 约束
- 全平台所有前端页面（路由、板块标题、Tab标签、卡片表头、表格列名、筛选框、图例、按钮）与后端数据契约（VO/DTO 字段注释），**必须严格以本标准字典表中的 `🌟 统一标准显示名称` 为唯一准则**；
- 严禁任何子模块独立定义同义别名或在文案中混入个性化副标题。

### 2. 严格禁止出现「环比」数据与计算
- 鉴于变压器与高压电缆等重型工业产品的排产呈现明显的批次性与季度性波动，月度/周度短期“环比”极易受到当期大单交期与产线检修的失真干扰；
- 全系统全面禁止出现任何“环比”数据、环比升降率、环比走势或环比分析标签。

### 3. 同比命名统一收敛
- 系统的年度同期对标名称强制固定显示为**「同比」**二字，格式统一为：`同比: -4.5% ↓` 或 `同比: +2.1% ↑`；
- 表格列名统一为 `同比`，严禁添加后缀修饰词。

### 4. 44px 工业高密度人机工程
- 所有统一字段纳管与呈现表格，行高强制固定为 **`44px`**（`h-[44px]`）；
- 字体采用 14px 工业等宽/标准字体阶梯，确保在 1080P 及以上工业大屏与工控机中呈现极佳的扫描阅读效率。

## 四、 QA 验收准则与破坏性测试矩阵 (Gherkin Scenarios)

### Scenario 1: 检验页面板块标题与字段命名合规性
```gherkin
Given 自动化测试机器人遍历访问全平台 76 个页面路由
When 读取页面内所有 DOM 标题元素 (h1, h2, h3, h4) 及表格表头 (th)
Then 页面上严禁出现任何在 ❌ 严禁使用的旧称/混淆词 列表中的词汇（如“电力负荷与消纳整体监测”、“产品种类”、“关键制造工序能耗管控指标”等）
And 必须 100% 严格匹配 🌟 统一标准显示名称
```

### Scenario 2: 全域环比数据禁绝门禁验收
```gherkin
Given 平台处于正常运行状态
When 检查所有图表 Tooltip、卡片数值标签、时序走势图及导出 Excel/CSV 报表
Then 不得检索到包含“环比”、“MoM”、“上月环比”或环比百分比数值的任何字符串
And 所有时序年度对比指标统一标记为“同比”
```

### Scenario 3: 分母隔离与工业单位一致性
```gherkin
Given 用户在能效对标分析页面切换“变压器产业”与“线缆产业”
When 查看单耗指标数值与图表 Y 轴单位
Then 变压器单耗单位必须严格为“kgce/kVA”，线缆单耗单位必须严格为“kgce/km”
And 严禁变压器与线缆产量进行任何直接跨产业加总运算
```

### Scenario 4: 新名词/新术语增加时的确认与合规录入门禁
```gherkin
Given 系统在后续需求演进或新设备接入中产生未在字典中收敛的全新字段
When 工程师或 AI Agent 计划在原型或代码中引入该新名词
Then 严禁直接硬编码或私自创建新字段
And 必须先向用户提出标准录入提案（包含建议名称、英文Key、所属分类、量纲单位及防错规则）
And 在获得用户明确批准确认后，方可将其统一补充录入至全域字典表及代码常量库（Web端业务界面保持纯净基础数据管理，不展示此表）
```
