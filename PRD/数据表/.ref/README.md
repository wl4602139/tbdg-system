## 构成关系（V2.2 核心）

`compose.py` 把「指标 ↔ 参数」的单向引用升级为三级链路：

```
指标 IND-035 单位产量能耗（变压器-特高压-器身干燥）  tce/万kVA
 ① 输入项 · 分子   EN-KT02   工序综合能源消费量（变压器-特高压-器身干燥）   tce   [复合参数]
 ②     分项        EN-KE15   工序电力消费量（变压器-特高压-器身干燥）       kWh   [原子参数]
 ②     分项        EN-KS02   工序蒸汽消费量（变压器-特高压-器身干燥）       t     [原子参数]
 ① 输入项 · 分母   OUT-KM01  工序产品产量（变压器-特高压-器身干燥）         万kVA  [原子参数]
```

三处可见：02 表第 23 列、03 表第 19 列、09 表（逐行展开，214 行）。
复合参数分项规则定义在 `compose.py` 的 `expand()`：EN-KT*（同产线同工序的电 / 蒸汽）、EN-P01、
EN-013、EN-017~020、EN-015、EN-032、CAR-001；泛化汇总口径由 `AGG_POINTER` 指向明细系列。

**待确认清单**：11 个工序的「综合能耗」与「电力消费量」是两个独立变量，说明还存在非电能源品种但源表未单列，
输出在 09 表表尾，需项目公司确认后补充编码。

## 工具坑（务必注意）

1. **以英文字符 `=` 开头的字符串写进单元格会被当作公式**。openpyxl 保存后该单元格 `data_type='f'`，
   用 `data_only=True` 读回是 `None`，且 xlsx 内容无声损坏。构成说明、算式等文本**必须用全角 `＝` 开头**。
   `assemble.py` 的 `_esc_eq()` 做统一兜底；新增数据时仍应主动避免。
2. 公式缓存值注入依赖 `layout.json`（由 `build2.py` 输出 01 页行号），不要再在 `inject.py` 里硬编码 `B37` 之类的行号——
   01 页区块增减会让行号整体位移。
3. 全表公式单元格扫描自检：`sum(1 for n in wb.sheetnames for row in wb[n].iter_rows() for c in row if c.data_type=='f')`
   应恰好等于 01 页的 38 个（1 匹配行号 ×2 + 参数属性 24 + 指标属性 12）。

## 指标源表已知坑

1. 分组标题行（整体指标 / 产品管控 / 关键工序）出现在 col B 且非数字，需在解析时跳过并作为分组标记。
2. `A` 列序号不连续，**`B` 列才是 1~94 连续序号**，指标编码以 B 列为准。
3. 指标名称的产线-工序在**最后一个括号组**内，部分名称括号后还有附注文字（IND-069/070），不能用 `$` 锚定。
4. 变量单位有两种写法：`单位kWh` 与 `单位为t`，正则需兼容 `单位\s*[为是]?\s*[：:]?`。
5. 变量符号中偶有 `=` 误写（如 `Q套-干燥=电`），需归一化为 `-`。
6. 单位口径差异：蒸汽有「质量 t」与「热量 GJ」两套；`EN-020 总用电量` 原表分母写「千kWh」。
7. 源表文字笔误：全表将「电力消费量」写作「电能源消费量」，`assemble.py` 中已统一勘误归一。
8. IND-011 水资源消耗量的「指标说明」未列变量行，指标定义等于 EN-026，由 `compose.py` 的 `IMPLICIT_INPUT` 补录。

## 需求清单已知坑

1. 9.16 与 8.27 两版**内容不一致**：8.27 有「零碳关键事件」「储能日充放分时电量（10 项）」「产量（线缆 / 非线缆）」，
   9.16 删除并新增「重点设备额定负荷 / 蒸汽流量」「热泵与空调系统整组参数」「氮气费用」「生产单元能耗计量数据」。
   本版以 **9.16 为准**，8.27 独有项凡有价值者保留并在 08 表标注理由。
2. 8.27 有若干**序号为空**的附表行（储能日充放尖峰平谷深谷电量 10 行），解析时需允许 seq 为空。
3. **单位口径冲突**：油品清单按 L / 参数表按 t；绿证清单按「个」/ V1.0 按「张 / MWh」；电量清单用 MWh / 参数表用 kWh；
   储能装机容量「MW/MWh」为复合单位；储能收益「元」与绿电收益「万元」不一致。均已拆项或加系数解决。
4. 清单中「热泵供热面积 / 空调供冷面积」来源标「界面手动录入」但备注写「15 分钟」，按静态台账处理。
5. 「服务器资源」段为硬件部署需求，不进入参数表。

## 清单文本导出（源 .et 更新后重跑）

```bash
"$PY" -c "
import xlrd
for f,out in [('“双中心”数据需求清单9.16(1).et','.ref/req916.txt'),
              ('“双中心”数据需求清单V1.0 (8.27)(1).et','.ref/req827.txt')]:
    wb=xlrd.open_workbook(f); s=wb.sheet_by_index(0); lines=[]
    for r in range(s.nrows):
        vals=[]
        for c in range(s.ncols):
            v=s.cell_value(r,c)
            if isinstance(v,float) and v==int(v): v=int(v)
            vals.append(str(v).replace(chr(10),' // ').strip())
        lines.append('r%-3d|'%r+'|'.join(vals))
    open(out,'w',encoding='utf-8').write(chr(10).join(lines))
"
```
