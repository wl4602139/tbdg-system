一、项目概述

本项目面向特变电工电装集团，建设统一的「零碳数字化管理平台」总览门户，向下汇聚两大业务平台：零碳园区集控中心（面向园区能碳集中监管与减排）与产品碳足迹集采中心（面向产品级碳足迹核算、CBAM 应对与认证）。 进入总览后提供左右两个大入口，点击进入各自业务平台；共性的系统管理放置于总览页右上角，两大平台共享账号权限体系。

零碳园区集控中心

9 个一级功能：集控大屏、集中监管、能耗能效分析、碳管理、零碳项目评估、统计报表、告警管理、基础配置、智能助手。

产品碳足迹集采中心

8 个一级功能：对外示范窗口、多维分析、实景数据库、CBAM 管理、第三方认证管理、因子库管理、基础配置、数据接口。

二、建设目标

  • 1打造集团对外示范窗口，可视化呈现零碳建设成效与产品碳足迹水平，面向领导层与参观对象。
  • 2实现园区能碳集中监管、能耗能效分析、碳排放核算与告警，支撑双碳目标管理与辅助决策。
  • 3建立产品级碳足迹实景核算、溯源、报告能力，并提前应对欧盟 CBAM 碳边境调节机制。
  • 4构建特变电工各产业本地化因子库，统一因子构建、版本管理与下发，打通股份与经营单位系统接口。
  • 5提供第三方认证便捷对接，统一认证资料、申请与证书生命周期管理。

3能耗能效分析单位产值能耗分析按分类产品展示单位产值能耗，数据变化趋势与同环比分析，识别异常单位产值能耗。—

4碳管理碳排放核算获取能源消耗数据（月/季/年周期自定义），引用因子库计算组织碳排放量及单位产值/产量碳强度，趋势分析识别异常；核算公式可配置、可追溯，自动校验完整性与一致性。—
4碳管理碳排放分析按排放源、能源类型、车间等维度拆解碳排放构成；不同维度同环比、累积量趋势分析，识别异常点与成因。—
4碳管理碳报告与核查支撑内置模板自动生成排放报告，支持自定义上传模板；历年报告在线归档、对比分析；组织层面汇集碳核算过程数据支撑第三方核查、导出。—
5零碳项目评估项目档案管理各项目公司在线填报基本信息、节能技改、绿电替代、储能配置、投资与收益、关键节点日期、预期减排与收益，上传附件并自动汇总形成统一项目库。—
5零碳项目评估模型管理包含实时监控模型及项目经济效益评估模型，支持模型修改维护、版本管理、迭代与历史回溯。—
5零碳项目评估实时监控与效益评估按定义规则自动计算光伏、储能、热泵等零碳项目经济效益（节费/收益）与环保效益（碳减排量），内置行业标准计算模型，展示投资回收期、IRR、减排水平等经济性指标。—
5零碳项目评估零碳园区自评估各园区在线勾选/填报建设项完成情况及进度，结合已有能耗/碳排数据自动计算建设水平，按预设评估模型生成综合评分及进度可视化。—
6统计报表能源用量/成本/单耗/碳排放报表自动生成月/季/年能源消费、成本、单耗、碳排放报表，涵盖电气水蒸汽（当量值/等价值可选）与折标煤量，支持同比环比与导出。—
7告警管理告警规则配置按能耗、单耗、碳排放、项目效益等多维度自定义规则：触发条件（阈值/持续时间/偏差率/同环比/标杆值偏差，多条件与或组合）、告警级别（提示/警告/严重）、推送策略、规则模板、规则生命周期管理、生效范围与适用对象。—
7告警管理告警处理责任人在线确认告警、闭环后状态变更"已处理"；历史告警查询归档，按状态/责任人筛选，便于追溯考核。—
7告警管理告警推送灵活配置推送规则：接收范围（角色/指定人员/组织架构）、主送与抄送、分级推送策略、多渠道（站内/企微/短信/邮件/电话语音）实时推送。—
8基础配置账号权限 / 碳排因子 / 费价模型 / 能源转换工具 / 接口配置管理 / 数据录入统一账号与多级组织架构权限；碳排因子多版本并存与管理；分时/阶梯/基本电费等费价模型；折标煤系数与能源单位换算工具；接口连接参数与字段映射；线下数据人工录入。—
9智能助手语音唤醒/智能问数/语音页面跳转自定义唤醒词，中英文语音转文字识别；自然语言问数（如"上个月哪个工厂单耗最高"）返回结果与图表；语音命令跳转对应页面（深层直达）。—

五、产品碳足迹集采中心 · 功能清单

序号一级功能二级功能功能说明功能定位
1对外示范窗口集团驾驶舱可视化展示集团各园区、各产业碳足迹数值、分布、构成、趋势及热力图，识别高排放环节；下钻至各经营单位产品碳足迹；实时显示实景库订单数、因子库因子数量、认证产品数量；底部轮播行业奖项、行业标准等荣誉成果。对各大园区及各经营单位碳足迹集中管控与辅助决策
2多维分析产品碳足迹总览展示各产线、产品系列碳足迹分布与构成，支持按产线、产品系列筛选，分析红黑榜，可下钻至具体经营单位及生产订单。横向/纵向/对标分析，识别碳排热点并模拟减排场景
3多维分析同品类横向对比同一产品规格在不同工厂、批次间横向对比，差异分解图（原材料/生产/运输）定位核心差异原因；排名视图快速识别低碳标杆与高碳改进对象。—
4多维分析碳热点分析与模拟依据生产环节及原材料自动生成碳足迹构成饼图/柱状图识别排放热点；支持"原材料替换""绿电接入"等减排潜力模拟，辅助低碳技术选型。—
5多维分析基准管理分析自定义多级基准值（年度目标、行业标杆），展示集团产品与行业标杆差距。—
6实景数据库碳足迹核算按产业/产线/产品类别/型号/订单的在线核算；查看各经营单位实景核算（链接本地系统），通过地图链接，提供两种入口。依据各经营单位核算结果与本地系统进行实景核算、溯源、报告
7实景数据库原始数据穿透数据链溯源，一键生成从原始数据（BOM、能耗、因子）到最终结果的计算路径图，涵盖原材料获取/运输、生产制造、废弃物明细，并关联至各经营单位对应订单。—
8实景数据库碳足迹报告依据 ISO 14067 自动生成碳足迹量化报告，支持 Word/PDF 导出，附带报告编号及验证二维码。—
9实景数据库能耗追踪依据能耗分摊算法实现对产品型号及订单级的能耗追踪与展示。—
10CBAM 管理合规管理管控范围判定：通过产品名称/HS 码进行欧盟 CN 码匹配，自动创建产品映射台账，支持豁免资格预评估；资质管理：统一维护 EORI、进口商授权、境外工厂注册等全类型 CBAM 资质，自动校验有效期。提前应对 CBAM
11CBAM 管理产品与客户产品库管理（绑定 HS-CN 映射、生产工艺、排放因子）；客户管理（欧盟进口商主体、EORI、申报资质）；订单关联（外贸出口订单与产品、生产设施绑定，自动抓取货量与报关信息）。—
12CBAM 管理成本测算出口成本测算（碳排放量 × 当期碳价，多情景模拟对比）；默认值查询（内置 CBAM 官方各行业默认排放因子库，一键套用官方基准值）。—
13CBAM 管理知识库CBAM 知识库查询（法规原文、CN 管控清单、申报指南、BTI 分类裁定案例，关键词检索）；CBAM 智能助手（语言交互式解答编码匹配、排放核算、季度申报、资质注册等疑问）。—
14CBAM 管理供应商碳管理录入关键原材料（硅钢片、铜、铝）供应商碳足迹数据、绿色资质，形成"供应商碳绩效地图"，满足 CBAM 前驱物数据导入要求。—
15第三方认证管理认证资料维护依据框架范围内认证机构提供的标准化产品碳足迹认证资料模板进行维护，供各经营单位下载、申报认证。第三方便捷认证对接管理
16第三方认证管理认证申请各经营单位按需在线填报产品碳足迹评价与认证需求，下载资料模板，支持申报材料上传。—
17第三方认证管理认证结果管理统一归档认证结果（证书编号、产品型号、认证机构、有效期、附件）；证书生命周期管理（到期提醒、过期禁用、变更续期），保留历史版本，支持导出与查询。—
18因子库管理股份因子同步待股份公司产品碳足迹系统上线后，可从股份碳足迹系统同步原材料、能源等因子。建立特变电工各产业本地化因子库

20因子库管理因子集构建能源碳排因子集、原材料因子集（变压器/线缆/其他产业）、原材料运输因子集的梳理，成果经招标方确认后固化；提供因子集查询/展示/修改，所有因子带版本标签。—
21基础配置账号权限复用集控中心系统账号权限，集团/园区/经营单位三级权限，权限细化至按钮级；所有登录、数据修改、因子变更操作记录审计日志，日志不可删除。基础支撑

23基础配置产品品类管理建立并展示集团级产业产品分类树（产业 → 产线 → 产品类别 → 型号）。—

六、页面与交互设计

总览门户页

  • 顶部左侧：集团 Logo 与「特变电工电装集团」品牌名；居中：大标题「零碳数字化管理平台」+ 副标题 + 英文徽标；右上角：共性「系统管理」入口 + 「需求文档」入口 + 用户信息（头像/角色下拉）。
  • 主体：左右两个大入口卡片（零碳园区集控中心 / 产品碳足迹集采中心），含 3D 等距插画、功能要点列表、「进入平台 →」按钮，悬停高亮上浮。
  • 交互：点击卡片或按钮进入对应平台默认首页；点击「系统管理」进入共性系统管理页；用户头像下拉含「个人中心 / 切换角色 / 退出登录」。

平台通用框架

  • 左侧可折叠导航：一级功能带图标，含二级功能展开（点击父级展开/收起，锚点定位到页内 Tab）；顶栏含平台名、面包屑、园区/时间范围全局下拉、系统管理入口、返回总览、用户信息。
  • 页面内容区：页头（标题 + 定位说明 + 操作区）→ 工具栏（下拉筛选/搜索/主操作按钮）→ KPI 卡组 → Tab 分组 → 图表/表格；所有表格支持行内操作（查看/编辑/下载/穿透）。
  • 弹窗：新增/编辑/详情/穿透/测试连接均以模态弹窗承载，含表单校验、取消/确认；下拉项全部给出真实业务选项。

关键交互与下拉项

  • 全局下拉：园区（昌吉/天津/沈阳/西安/衡阳）、时间范围（今日/近7日/本月/本季/本年/自定义）、产业（变压器/线缆/开关/其他）。
  • 分析类下拉：维度（按产业/产线/产品类别/型号/订单）、对比对象（工厂/批次）、能源介质（电/气/水/蒸汽）、对标类型（行业对标/集团内对标）。
  • CBAM 下拉：欧盟碳价情景（低/当前/高/预期）、认证机构（TÜV/SGS/BV）、认证类型（碳足迹认证/EPD）、接口认证方式（Token/AppKey）。
  • 告警下拉：触发条件（阈值/持续时间/偏差率/同比/环比/标杆偏差）、级别（提示/警告/严重）、推送渠道（站内/企微/短信/邮件/电话语音）、生效状态（启用/停用）。

七、共性系统管理

系统管理为两大平台共性能力，入口置于总览页右上角，包含：账号与三级组织权限（集团/园区/经营单位，细化至按钮级）、 角色管理、数据安全（国密算法加密）、操作审计日志（不可删除）、消息通知配置。两大平台复用同一账号权限体系。

八、非功能性需求

安全性

等保三级；敏感字段国密（SM2/SM4）加密；审计日志留存 ≥180 天且不可篡改；参数化查询防注入。

性能

大屏首屏 ≤3s；核心图表交互响应 ≤1s；支持大数据量表格分页与虚拟滚动。

兼容与响应式

桌面优先，兼容主流浏览器；大屏适配 1080P/2K；关键页面移动端可查看。

可扩展性

因子/费价/核算公式可配置、多版本；接口字段映射可配置；模型版本化管理。
