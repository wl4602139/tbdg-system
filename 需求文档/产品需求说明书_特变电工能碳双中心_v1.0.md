## 第 1 章 项目概述

### 1.1 项目背景

本项目为 **特变电工（电装集团）能碳数字化双中心集成平台**，任务编号 `TBEA-DC-REQ-2026-0515`，需求发起方为集团能碳管理主管部门。平台以「零碳园区集控」与「产品碳足迹集采」为两大业务主轴，构建覆盖**组织级能碳管控**与**产品级碳足迹核算**的一体化数字化底座，支撑集团「双碳」目标分解、零碳工厂建设评估、产品碳足迹认证与国际绿色贸易合规（CBAM）等业务场景。

### 1.2 建设目标：双中心一体化

| 中心            | 定位            | 核心使命                                                                                 |
| :------------ | :------------ | :----------------------------------------------------------------------------------- |
| **零碳园区集控中心**  | 对内管控中枢        | 以「园区 → 经营单位 → 产线 → 产品 → 批次」为数据主线，实现能碳指标集中监控、能效分析、对标排名、项目评估与统计报表的全链路闭环                |
| **产品碳足迹集采中心** | 对外示范窗口 + 核算底座 | 以「产业 → 产线 → 产品类别 → 型号 → 订单」为数据主线，实现 LCA 全生命周期碳足迹核算、实景数据库、多维对比、第三方认证、因子库管理与 CBAM 合规申报 |

两中心共享同一套**组织树、指标体系与因子库**，形成「组织碳」与「产品碳」双视角互相印证的能碳数据体系。

### 1.5 组织与数据维度模型

平台采用**七层数据维度树**，是全部页面筛选、下钻与聚合的统一骨架：

```
集团 (Group)
└── 园区 (Park)                       共 6 个：衡阳 / 天津 / 山东 / 沈阳 / 西安 / 新疆
    └── 经营单位 (Org / Company)      共 37 家：天津变压器 / 鲁能泰山 / 沈变 / 西开电气 / 新疆众和 …
        └── 产线 / 车间 (Line)
            └── 产品种类 (Category)   变压器 / 线缆 / 开关 …
                └── 产品型号 (Model)  SG10-2500kVA / YJV-8.7/15kV …
                    └── 生产批次 / 订单 (Batch / Order)
```

| 层级      | 统一标识字段                        | 数量规模  | 权威来源      |
| :------ | :---------------------------- | :---- | :-------- |
| 园区      | `parkId` / `parkName`         | 6     | 组织树基础字典   |
| 经营单位    | `orgId` / `orgName`           | 37    | 组织树基础字典   |
| 产线 / 车间 | `lineId` / `lineName`         | 按单位配置 | MES 主数据   |
| 产品种类    | `categoryId` / `categoryName` | 3 大类  | ERP 物料主数据 |
| 产品型号    | `modelId` / `modelName`       | 全量型号  | ERP 物料主数据 |
| 批次 / 订单 | `batchNo` / `orderNo`         | 时间序列  | MES 生产工单  |

**算法引用（`lib/benchmark.ts`）**

| 计算函数                     | 公式 / 规则                                                |
| :----------------------- | :----------------------------------------------------- |
| 达标系数 `achievement(v, m)` | 越低越好 → `benchmark / v`；越高越好 → `v / benchmark`；`≥1` 达标  |
| 距标杆差距 `gapPct(v, m)`     | `(v − benchmark) / benchmark × 100%`                   |
| 单指标状态 `metricStatus`     | `a ≥ 1.00` → 优秀；`0.85 ≤ a < 1.00` → 正常；`a < 0.85` → 异常 |
| 零碳综合得分 `compositeScore`  | 5 项指标 `min(1.15, achievement)` 平均 × 86，夹逼 `[45, 99]`   |
| 综合得分阈值 `compositeStatus` | `≥90` → 优秀（绿）；`78–89` → 正常（黄）；`<78` → 异常（红）            |

**（2）派生指标计算统一性（`lib/benchmark.ts` 全局唯一实现）**

| 计算函数                        | 业务含义   | 公式                                                                      | 消费页面           | 一致性状态 |
| :-------------------------- | :----- | :---------------------------------------------------------------------- | :------------- | :---: |
| `achievement(v, benchmark)` | 达标系数   | 越低越好：`benchmark/v`；越高越好：`v/benchmark`                                   | 对标、红黑榜、总分卡     |   ✅   |
| `gapPct(v, benchmark)`      | 距标杆差距  | 越低越好：`(v-benchmark)/benchmark×100%`；越高越好：`(benchmark-v)/benchmark×100%` | 对标、明细表、管理抓手    |   ✅   |
| `metricStatus(achievement)` | 单指标状态  | `≥1` 优秀；`0.85~1` 正常；`<0.85` 异常                                          | 指标管控、对标        |   ✅   |
| `compositeScore(5 指标)`      | 零碳综合得分 | 各指标 `min(1.15, achievement)` 取均值 × 86，夹逼 `[45, 99]`                     | 对标、红黑榜、集采驾驶舱   |   ✅   |
| `compositeStatus(score)`    | 综合得分状态 | `≥90` 优；`78-89` 正常；`<78` 异常                                             | 红黑榜、对标明细表、管理抓手 |   ✅   |
| YoY 判色                      | 同比变化着色 | 越低越好且降 = 改善绿；越高越好且升 = 改善绿；反 = 恶化红；`\|v\| < 0.5%` = 持平灰                  | 指标管控、趋势页、全部报表  |   ✅   |

> **校验结论**：全工程指标口径**唯一实现于 `lib/benchmark.ts`**，不存在双写或多套口径的偏离风险 —— 判定为**一致性 PASS**。
