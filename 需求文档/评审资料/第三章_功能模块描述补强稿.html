原材料碳排因子 · 第⑤段替换

补强后文本
EF_mat = Σ ( k = 1 → m ) [ W_k ÷ Σ ( j = 1 → m ) W_j × EF_k ]　　　　　（多供应商混料加权综合因子）
ΔEF_pct = ( EF_current − EF_default ) ÷ EF_default × 100%　　　　（因子版本变动偏离率）
DQR = ( TeR + GeR + TiR + ReR ) ÷ 4　　　　　　　　　　　　　　　　（数据质量四维综合评级）
C_material = Σ ( i = 1 → n ) ( M_i × EF_mat,i )　　　　　　　　　　（产品原材料阶段总碳足迹）

变量定义与取值约定：
W_k 为向第 k 家供应商采购该物料的实际重量（kg 或 t）；EF_k 为对应供应商核证因子；

EF_mat 保留 4 位小数；C_material 保留 2 位小数（kgCO2e）。

碳足迹总览驾驶舱

新增文本
取值示例：某 220kV 油浸式变压器 E_raw = 118,420.00、E_trans = 3,150.00、E_manuf = 21,600.00、E_test = 1,240.00、E_pack = 890.00 kgCO2e，则 E_PCF = 145,300.00 kgCO2e，其中 R_原材料 = 81.50%、R_制造 = 14.87%。若 Price_EU_ETS = 82.00 €/tCO2e、Price_Domestic = 62.00 €/tCO2e、Export_Qty = 200 台、Embedded_Carbon = 145.30 tCO2e/台，则 Save_CBAM = 200 × 145.30 × ( 82.00 − 62.00 ) = 581,200.00 €。

横向对比

新增文本
取值示例：A 厂 CF_unit = 145.30、B 厂 = 138.60、C 厂 = 151.20 kgCO2e/kVA，则 Mean_unit = ( 145.30 + 138.60 + 151.20 ) ÷ 3 = 145.03 kgCO2e/kVA。若基准值 Benchmark = 140.00，则 B 厂达标且排名第 1，A 厂与 C 厂超基准标红。

新增文本

新增文本

新增文本

新增文本
