2.1　定位与架构角色 替换

功能定位：集中监管板块的可扩展指标中枢，面向园区能碳专员提供「自主定义指标口径 → 自动采集计算 → 阈值三色监视 → 台账留痕导出」的闭环能力，用于承载无法被固定 10 项核心指标覆盖的园区个性化管理口径（例如「吨线缆综合能耗」「单台变压器空载损耗」「万元增加值碳排放」等），彻底解决"管理口径变了、系统指标没跟着变"的口径漂移问题。 承载角色：P2 园区能碳专员（主视角，负责指标定义、试算、发布与日常监测）；P1 集团决策层（只读查看已发布的自定义指标卡片，不参与定义与发布）。 页面路由：/monitor/indicators/custom（左侧导航：集中监管 › 自定义指标监测）。 上游依赖：用能在线监测的实时采集数据；用能监测的日结台账；指标管控的 10 项核心指标及其组织聚合口径；第四章《系统管理、基础参数设置》的基础数据管理（基础参数）、折标煤系数库、能碳基础因子管理；组织架构六级主数据。 下游输出：集中监管指标卡片矩阵中的自定义指标卡；数据变化详情的归因输入；统计报表的自定义口径来源；自定义指标台账的导出文件。 数据权限：本模块遵循组织维度 RLS。指标的定义与发布限 P2 及以上角色、且仅限其数据范围内操作；集团决策层（P1）对已发布指标只读。指标「数据范围」不得超出操作者自身数据范围，越权保存或访问返回 HTTP 403 并记数据访问审计日志。

2.5　核心数学模型与算法框架 新增

（1）指标值计算（公式求值） V = f( P₁, P₂, …, Pₙ ; K₁, K₂, …, Kₘ ) Pᵢ 为引用自平台的基础参数或核心指标的时序取值（按指标配置的数据范围与时间粒度取数）；Kⱼ 为用户在公式中直接写入的常量。表达式先按中缀转后缀（逆波兰式）再求值，支持 + − × ÷、括号、单目负号与聚合函数 SUM / AVG / MAX / MIN。 （2）折标能耗类指标 E = Σ ( Qᵢ × kᵢ ) Qᵢ 为第 i 种能源介质实物消耗量；kᵢ 为第 i 种介质折标准煤系数，引用 GB/T 2589-2020 当量值，取自第四章折标煤系数库。 （3）单耗类指标（自定义口径示例） U = E / O E 为综合能耗（tce）；O 为分母口径量（产量 / 产值 / 增加值对应单位）。分母为 0 时按除零兜底显示 -- ，严禁 NaN 或白屏。 （4）同比 / 环比 Δ_yoy = ( V_t − V_(t−12) ) / V_(t−12) × 100% Δ_mom = ( V_t − V_(t−1) ) / V_(t−1) × 100% t 为当前周期序号；时间粒度为月时，t−12 指上年同月、t−1 指上月。分母为 0 或同期数据缺失时，同比 / 环比显示 -- 。 （5）三色状态判定（能耗类 / 单耗类指标，越低越优） · 优秀：V ≤ V_excellent · 正常：V_excellent ＜ V ≤ V_normal_max · 异常：V ＞ V_normal_max （6）精度与容差 指标值小数位按指标配置（0~6 位，默认 2 位）；同比 / 环比固定保留 1 位小数；占比类指标各项四舍五入至 100.0%，偏差超过 0.1% 触发配平自检。 取值示例（可作开发自测基准）：某线缆园区自定义指标「吨线缆综合能耗」= ( 电力折标量 + 天然气折标量 ) ÷ 线缆产量，分母口径单位为 km·mm²，指标单位 tce/万km·mm²，阈值分级配置为 优秀值 0.82 / 正常值上限 0.95 / 异常值下限 0.95 以上。

2.6　展示、对标与判定口径 新增

（1）卡片展示口径：卡片固定呈现「指标名称 + 大号数值 + 计量单位 + 同比箭头 + 三色状态点」；数值按指标配置的小数位展示；缺失期保留 -- 并附"数据待上报"微标注，严禁以 NaN 或 0 值冒充。 （2）三色口径（能耗类 / 单耗类越低越优）：绿＝优于或等于优秀值；灰＝介于优秀值与正常值上限之间；红＝高于正常值上限。三色仅表达客观数值区间，页面严禁出现"表现优异""落后单位"等定性评语，统一以客观数值与环比自解释。 （3）对标口径：自定义指标默认仅在本数据范围内与历史同期做纵向对比，不参与集团横向排名与达标统计；如需纳入集团横向对标，须在指标定义中勾选「纳入集团对标」并经 P1 审批，审批通过后卡片与台账须标注"自定义口径"字样，与集团统一下发的核心指标明确区分。 （4）台账口径与粒度：时间粒度分日 / 月 / 年三档，跨粒度不混算、不折算；粒度切换后台账整体重算并标注当前粒度；月度值不做逐日累加校验，年度值由年度分子分母直接计算。 （5）排序与筛选口径：数据概览区默认按指标编码升序，可切换为按状态排序（异常优先）；台账明细区支持按三色状态、时间范围、指标名称 / 编码筛选。 （6）版本口径：指标口径（公式、单位、阈值）变更须先停用旧版再发布新版，历史台账保留当期生效口径快照；口径变更不追溯重算已发布周期，避免历史考核结论被推翻。 （7）基准来源口径：折标煤系数取自 GB/T 2589-2020 与第四章折标煤系数库；碳排因子取自第四章能碳基础因子管理；任一因子版本超出有效期时，指标值照常计算但在台账中标注"因子待升级"。

2.7　边界条件、异常处理与防错规则 新增

（1）公式引用不存在的基础参数或核心指标：阻断保存，返回 E_SYS_KPI_CUSTOM_EXPR_INVALID，并在公式编辑器中高亮未识别的变量名。 （2）指标编码重复：阻断保存，返回 E_SYS_KPI_CUSTOM_CODE_DUP，高亮指标编码字段。 （3）阈值分级非法（不满足 优秀值 ≤ 正常值上限 ＜ 异常值下限）：阻断保存，返回 E_SYS_KPI_CUSTOM_THRESHOLD_INVALID，并指出越界的阈值项。 （4）删除被引用指标：阻断删除，返回 E_SYS_KPI_CUSTOM_IN_USE_DELETE_DENIED，列出引用方清单（指标卡片矩阵 / 数据变化详情 / 统计报表）。 （5）自定义指标数量超配额：同一数据范围内自定义指标数量超过配额上限（默认 100 个）时阻断新增，返回 E_SYS_KPI_CUSTOM_LIMIT_EXCEEDED。 （6）分母为 0：按除零安全兜底显示 -- ，返回 E_VAL_KPI_CUSTOM_DIV_ZERO；不抛技术错误码、不白屏、不用 0 值冒充。 （7）未发布指标：状态为「草稿」的指标不进入数据概览与台账，不参与任何计算、排名与导出。 （8）数据范围越权：指标「数据范围」超出操作者自身数据范围时阻断保存，返回 E_AUTH_RLS_SCOPE_DENIED；越权读取返回 HTTP 403 并记数据访问审计日志。 （9）公式引用因子过期：所引用的折标煤系数或碳排因子版本已超出有效期时，指标值照常计算并在台账标注"因子待升级"，返回 E_VAL_FACTOR_EXPIRED。 （10）并发编辑冲突：同一指标被两名用户同时编辑时按行版本号比对，后提交方提示"该指标已被他人修改，请刷新后重试"，返回 E_SYS_CONCURRENCY_LOCK。 （11）越权写拦截：非授权角色（非 P2 及以上，或数据范围外）调用本模块写接口时返回 HTTP 403，触发 E_AUTH_RBAC_FORBIDDEN。 （12）导出台账超限：单次导出记录数超过 50,000 行时拒绝导出，返回 E_SYS_EXPORT_LIMIT_EXCEEDED，提示缩小筛选范围或分批导出。 （13）聚合函数空集：对空集使用 SUM / AVG 时按 -- 兜底（AVG 不返回 NaN，MAX / MIN 不返回 0）。
