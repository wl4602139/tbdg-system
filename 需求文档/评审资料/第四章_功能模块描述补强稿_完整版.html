2　权限管控

板块导言 | 权限管控

本板块是系统管理模块的权限治理中枢，也是全平台访问控制与数据隔离的唯一规则来源。板块遵循「组织定边界、账号定身份、角色定权限、菜单定资源」四层递进结构，下辖 4 个三级功能模块：组织管理（组织主数据）、用户管理（账号生命周期）、角色与权限（功能权限与数据范围配置）、菜单与功能（功能资源底座）。 边界声明：本板块只维护权限规则，不产生任何业务数据；权限变更一经保存即刻生效，并全量记入日志管理。本板块是全平台最先初始化的模块，其余全部业务模块的组织维度筛选、数据范围隔离、按钮可见性均以其配置结果为基准，不得在业务模块内就地改写。 输入输出链：组织管理产出组织树 → 用户管理绑定账号-角色-所属机构-数据范围 → 角色与权限定义角色可用功能点与数据范围 → 菜单与功能提供全量功能资源（最小权限颗粒）供角色勾选。四者构成不可跳跃的单向链；任一环节数据不完整即阻断下游操作入口。

2.3.5　核心数学模型与算法框架 替换

（1）功能点授权完整度 已授权数 N(role, platform) = Σ 该角色在该平台勾选的功能点数量； 完整度 = N / M，其中 M = 该平台功能点总数。 示例：集采平台 M = 36，集团管理员 N = 36 → 完整度 100%；审计员 N = 4 → 11.1%。 （2）权限判定算法（二维判定：功能级 × 数据级） Can(U, action, target) = (action ∈ Perms(role(U))) ∧ (org(target) ∈ V(U)) 其中 Perms(role) 为角色的功能点集合，V(U) 为用户 U 的数据范围可见节点集（见 2.2.5 数据范围解析算法）。 两项均为真方可执行；功能级不通过返回 HTTP 403（E_AUTH_RBAC_FORBIDDEN），数据级不通过返回 HTTP 403（E_AUTH_RLS_SCOPE_DENIED）。 （3）权限不可扩大原则 设操作者 O 的功能权限集为 P(O)、数据范围可见集为 V(O)；被配置角色 R 的权限集为 P(R)、范围集为 V(R)。 约束：P(R) ⊆ P(O) 且 V(R) ⊆ V(O)。超出部分在保存时被过滤，并返回 E_SYS_ROLE_PERM_EXCEED。 （4）角色基线（截图 #39 坐实） · 集团管理员（内置，2 名用户，数据范围＝全集团，集控 16 / 集采 34 / 系统 19） · 园区管理员（内置，6 名用户，数据范围＝所属园区，集控 16 / 集采 36 / 系统 3） · 经营单位（自定义，23 名用户，数据范围＝本经营单位，集控 7 / 集采 4 / 系统 3） · 节能专员（自定义，11 名用户，数据范围＝所属园区，集控 3 / 集采 34 / 系统 0） · 审计员（内置，1 名用户，数据范围＝全集团（只读），集控 4 / 集采 4 / 系统 3） 精度与容差：计数为整数；完整度按百分比保留 1 位小数，无容差。

本板块是全平台碳排放核算的基准数据源，向上为集控中心的能耗碳排放统计、集采中心的碳足迹核算提供唯一取数依据。板块按介质与用途划分为三类基准：电力碳排因子（外购电力）、能源活动碳排因子（燃料燃烧、外购热力、制冷剂逸散）、折标煤系数库（能耗折算）。三者在数值口径上相互衔接——同一能源品种的排放因子与折标煤系数须单位一致、口径同源。 边界声明：本板块只管理因子的版本与数值，不产生任何核算结果。因子一经版本发布即为受控数据，业务模块只能只读引用；任一因子升版，即触发下游核算视图按新版本重算。国家标准强制受控字段（如 GB/T 2589-2020 的电力 0.1229、天然气 1.2143）禁止在本模块内随意修改，变更须走标准换版流程。 输入输出链：外部基准（生态环境部公告 / IPCC 指南 / GB/T 2589 / 股份公司下发）经线下核定后录入本板块 → 发布因子版本 → 第三章碳足迹核算与集控能耗统计只读取数。本板块的权威性由「版本 + 数据来源」双重标识保证：任一核算结论都必须可回溯到具体的（因子品种, 版本, 数据来源）三元组。

4.1.5　核心数学模型与算法框架 替换

（1）分时电费计算 C_elec = Σ_t (Q_t × P_t)，t ∈ {深谷, 低谷, 平段, 高峰, 尖峰} 其中 Q_t 为 t 时段用电量（kWh），P_t 为该时段电价（元/kWh）。 （2）两部制电费 C_basic = max(C_capacity, C_demand) C_capacity = S_cap × 31.00（元/(kVA·月)），S_cap 为变压器容量（kVA） C_demand = P_max × 48.00（元/(kW·月)），P_max 为最大需量（kW） （3）力调电费考核 C_pf = C_base × k(cosφ)，基准功率因数 cosφ₀ = 0.90 cosφ ＞ 0.90 → k(cosφ) ＜ 0（节能减收） cosφ ＜ 0.90 → k(cosφ) ＞ 0（考核增加支出） （4）直供电碳交易溢价 C_carbon = Q × α，α 为碳交易价格系数（元/kWh；截图示例 0.0000） 当 α ＞ 0 时，该溢价计入产品碳足迹的成本分量；同时工厂外购绿电及绿证 / 环境权益证书，计入产品碳足迹排放因子的扣减项。 （5）阶梯气价 C_gas = Σ_k (Q_k × P_k)，Q_k 落入第 k 档月度用气量区间，P_k 为该档对应结算单价。 （6）版本号生成规则 版本号 = "v" + 生效年(YYYY) + "." + 当年顺序号(NN，两位)，如 v2026.01。 （7）取值示例（截图 #44 坐实，夏季电费） 深谷 0.2650 元/kWh（新能源弃风弃光时段价）； 低谷 0.3520 元/kWh（燃煤 / 核电机组电价）； 平段 0.7250 元/kWh（燃煤基准电价）； 高峰 1.1690 元/kWh（日间电力生产活动电价）； 尖峰 1.4200 元/kWh（短期供需紧张调节电价）； 两部制：变压器容量单价 31.00 元/(kVA·月)、最大需量单价 48.00 元/(kW·月)； 力调考核：基准功率因数 COSφ = 0.90； 碳交易价格系数 = 0.0000 元/kWh。 价格依据：辽发改价格（2025）856 号（2026 年度沈阳市）。 （8）精度与容差 单价保留 4 位小数；成本金额保留 2 位小数，容差 ±0.01 元。

本板块是能碳统计与碳核算的产品维度主数据源，覆盖「分类—型号—指标—工序」四个层次的静态基准，为产量统计、单位产品能耗、工序能耗分摊与单品碳足迹核算提供标准化口径。四者构成自顶向下的分解链：产品类型（分类）→ 产品型号（具体产品）→ 生产工序（过程）→ 基础数据（指标字典），任一环节的编码或单位不一致，都会导致下游碳核算结果不可追溯。 边界声明：本板块只维护静态主数据，不产生动态产量或能耗数据。产品型号一经绑定工序并被核算引用，即成为受控主数据，禁止删除，只能停用。计量单位是本板块的核心约束——同名数据项若单位不一致，须通过独立编码区分（如「蒸汽消费量（热量）」与「蒸汽消费量（质量）」）。 输入输出链：产品类型管理（两级分类与编码）→ 产品型号管理（五级关联绑定）→ 生产工序管理（工序与产品中类、工厂多对多关联）→ 基础数据管理（指标字典与采集口径）→ 集控能耗分摊与集采碳足迹拆解。
